# RUN-0011 观照、下劈、地刺与48区内部结构

日期：2026-10-28。规格：[地图结构重构 v2](../../design/feature-map-reconstruction.md)。运行布局版本6，兼容旧4／5。

## 当前实现

- 48区共用原488房间、62区域连接，新增逐连接落差语义、侧龛、下层回环和6处R5地标井；前进出口实际换层。隐藏区原门返程与终局无前进门作明确豁免。
- 305组地刺、47段必经下劈链、91处一次性遗存侧龛均来自逐区结构表。潜刺的周期不随镜头变更，观照只提供当前时代的信息。
- VC在M02屋脊遗迹发放；三档取景不暂停、不改变碰撞和攻击盒。C优先于V，Boss拒绝远眺而保留近察。
- 空中下攻击锁定方向，顶面反弹−380、定格0.06s，侧面仅伤害；不赠送未解锁PA／P2，不重置攻击冷却。
- 刺固定1点、0.25s控制锁与1s保护；480px内找避开刺的可站立落脚，无落点回检查点。死亡仍走一次原有掉魂流程。

## 检查中实际修复

1. M13、M14、M22、M23、M33、M39存在多个单向落差组合造成的返程缺口；补侧索并记录`return_fixes`。
2. 通用平台遮挡原镜面、阻挡齿轮或割穿机关室地板；保护机关室，恢复侧向地板与剧情锚点落脚岛。
3. 新下层回环侵入普通爬升通道；收窄实体底板，保留真正的两侧入井和独立上桥面。
4. M01新增回环破坏了旧断桥的回岸点；恢复左右岸台，保留过去完整桥／未来断桥。
5. 侧龛遗存与未来封印重叠；调整交互位置，不把奖励放进实体墙。
6. 旧档在读取原布局版本前已由`load_map`写成新版本；改为提前捕获版本再迁移，避免漏补VC。
