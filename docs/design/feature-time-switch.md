## 规则与依据

立项案第二节、地图总控和第一章M01已按本次用户指令同步。免费切换、可站立的封闭空间允许留下，以及无立足点的原有安全复位仍保留。

1. 按 `switch_era`（默认Tab／手柄Y）时，先取得目标时代的地形快照，检测主角在当前位置的碰撞体。
2. 若碰撞体会与目标时代实体地形重叠，立即取消此次切换，显示准确提示“当前位置无法使用该能力”。保持当前时代、现有地形节点、角色位置、速度、生命及调查／机关进度；不触发死亡、复活、安全点搜索或切换成功动画，不消耗资源，也不添加失败冷却。
3. 玩家移出冲突区域后，可立即再次使用能力。反复按键只刷新提示，不累计伤害或执行延迟切换。
4. 目标地形不重叠且可站立，或可沿无遮挡路径落在有效平台上时，正常切换，保持位置与速度。封闭但可站立的桥洞不因封闭而禁止切换。
5. 目标地形不重叠但无有效落点时，沿用现有处理：切换、扣1生命并寻找附近可移动安全点；生命归零或附近无合格点时返回检查点。这个分支与卡墙拒绝严格分开，本次未修改其规则。

## 实现与状态顺序

入口为 `game/world.gd::_switch_era()`；场景 `game/main.tscn`，地形与交互数据由 `game/m01_layout.gd` 独占。输入来自 `InputActions` 动作层，设置面板和日志阅读时游戏暂停。

执行顺序：计算目标地形 → `_is_clear`预检 → 冲突则提示并return → `_has_support`检查落脚 → 必要时处理无支撑复位 → 更新时代并重建地形。必须在重建地形、改写时代和调用角色受伤接口之前完成卡墙预检，不能先切过去再撤回。

拒绝操作不清空跳跃／攻击／冲刺状态或输入缓冲。其“不移动／不改速度”指切换操作本身不改写，正常物理模拟与独立发生的敌人攻击仍继续；提示不会暂停世界或额外授予无敌。

当前 `_is_clear` 同时校验世界水平边界与上边界；超出地图边界同样取消切换并显示该提示，避免对非法坐标执行传送。碰撞检测使用角色物理体的24×40px尺寸及微小接触容差，不以贴图、皇冠或装饰轮廓判定卡墙。

## M01参数

- 世界3840×720，入口检查点(160,460)。
- 有效落差至多180px，落脚位置须可站立且下落路径无遮挡。
- 无支撑时安全点搜索半径480px，候选平台宽至少52px、顶面在80—660px，并检查角色有横向移动空间；624px低层也参与求解。
- 无支撑分支扣1生命；卡墙分支扣0生命、无复位。
- 失败提示显示6秒，再次失败刷新时长；不会阻止玩家移动或重试。
- 生命上限、移动和攻击数值由 `player.gd` 维护，本规格不复制其全部数值表。

这些为M01可玩灰盒当前值，需通过试玩再平衡，不据此宣称所有地图已验收。

## 教学与反馈

M01桥端石碑先演示正常切换。原“切入实体扣血”可选高台改为无伤的切换限制试台：过去站入墙体虚影后按Tab，看到无法使用提示并留在过去；移到空处再次按Tab即可进入现在。试台不阻挡主线，也不要求玩家死亡或损失生命。

HUD时代文字、地形、生命与角色位置在拒绝时均不跳变。原有日志、改键、葬帖、壁画、开闸状态继续有效，不需要迁移已有M01进度文件。

## 验收

- 墙体冲突时：准确显示提示，时代／地形节点／位置／速度／生命不变，未触发respawn。
- 生命为1时连续三次拒绝：不死亡、不回血、不传送，无失败冷却。
- 同一试台移到无重叠位置：立即成功切换，生命不变。
- 封闭且可站立的桥洞：允许正常切时，不扣血、不强制移出。
- 无实体重叠但无落点：原扣血复位正常；该分支致死仍回检查点。
- 葬帖、壁画、闸锁及两条出口不因新规则软锁；初始单跳完成实际往返。
