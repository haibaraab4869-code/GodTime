## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：一条海岸被反复借走又还回来——船队搁浅在这里不是海难，是海的账没结清；本区讲「资源被抽干之后，靠它活着的人去了哪」。
- **视觉母题**：搁浅龙骨、盐壳断面、烧焦帆索。
- **色彩基调**：过去 `#202849` 底 + 赭褐船木 `#BC8C64` + 湿盐反光 `#8FA6B8`；现在 `#142032` 底 + 冷灰盐壳 `#657987` + 焦黑 `#3A3230`。强调色统一用 `#B8642C`（朽铁钉），只在船骨接缝处出现——它是"人造物"的唯一标记。
- **情绪曲线**：进入——空得发亮的海床，脚下一踩就脆裂（荒凉 + 不信任地面）；中段——冷岸风庭的上升气流把人抬起来，第一次能横着飞（开阔，本区唯一的高点）；离开——720px 盐风带上滑过去，回头看整条搁浅船队排成一条线（宏大 + 代价）。

### 1.2 关卡结构

- **主脉**：R01 → R02 → R03 → R04 → R05（取 `PG`）→ R06（自验证）→ R07 → R08 → R09 → R10（`PG` 横渡）→ W15。
- **支脉**：
  1. R03 →（过去态潮位灌水浮船骨）R11 桅顶望台：叙事物 I-04 + 魂魄，死路，需在过去起跳、现在落地 → **跨时代单程**，可原路返（现在态木斗下垂绳）。
  2. R05 →（过去态浮舟横梁）R12 浮舟横梁：精英 EL-01 守 战技残篇 I-02，死路。
  3. R09 →（`PG` 上升气流）R13 焚帆架：叙事物空缺，只给高处视野与 2 处魂魄，无回环。
  4. R04 →（下沉）R14 盐壳裂窟：精怪 ELT-01（锁门），奖励 凶骨 I-01。
  5. R06 →（下沉）R16 盐蜮巢：精英 EL-02 守魂魄堆 ×3。
  6. R08 →（下沉）R15 沉舟腹：叙事物 I-05（两态合读）+ 潮位机关 D3。
- **结构类型**：**单主脉 + 六条一房深支脉**。理由：4.9:1 的横向岸线不允许出现第二条纵向主路（会破坏"岸"的单一方向），所有纵深度都压进上／下两层的单房支线，最长的支线只有 1 房深。

### 2.3 竖向设计

- **最大连续落差**：R10 内部 384px（起点平台 y=768 → 盐浆 y=1152），但玩家实际经历的单次落差是 232px（滑翔落点 y=1000）。全区无贯穿全高的竖井。
- **全高地标**：**搁浅龙骨拱**（R08，脊背宽 96，从 y=384 垂到 y=720）。它是全区唯一的"坐标系"：整条岸线上任何一点都能看见这条龙骨的两端；它在两个时代指向不同的东西——过去态龙骨下有水、脊背是干的（可走），现在态龙骨下是盐壳、脊背两侧塌了半米（需跳）。玩家靠"龙骨两侧的盐堆高度"判断自己现在是哪一态。
- 地标同时是**信息载体**：龙骨脊背上有 11 道吃水刻痕，过去态只能看见其中 4 道（水位高，刻度被淹），现在 11 道全露——这是本区叙事物 I-05 的另一半（在 R15 船舱里）。

## 3. 探索技能应用点

### 3.1 `PG` 凤凰滑翔（**本区取得 + 首次使用 + 自验证**）
- **应用房间**：R05（取得）、R06（自验证 300px）、R10（门 720px）、R13（支线上升气流）
- **设计意图**：交付一个"横向位移"能力，并立刻用它通过两种不同尺度的缺口——300px（教学）与 720px（主脉门），中间不插任何其他能力。
- **判定几何**：
  - 取得台：高 298（需上升气流，`PG` 未持有时也可借气流上升到台前，但台上无落点 → 见失败反馈）。
  - R06 断桥：300px 缺口、落差 160。滑翔水平 255 px/s、下降 45 px/s → 1.18 s 过桥、落 53px，余量充足。落点平台（y=928）经 2 级踏面（各 80，宽 96）回到 R07 门槛 y=768，**无 `PG` 的玩家也能原路爬回**，因此自验证失败不产生单向陷阱。
  - R10 盐风带：720px 缺口、落差 232、横风把有效水平压到 ≈200 px/s → 3.6 s、落 162px < 232，仍有余量。若无 `PG`：自由落体 232px 用时 0.65 s、水平仅 195px → 必落盐浆。
  - R13：上升气流 +220 抵消下降 45 → 净上升 175 px/s，可把滑翔变成爬升，是本区唯一的"高处钩子"。
- **失败反馈**：
  - 风场档位错（下压 -180）→ 人被按在坞底，看得见取得台但够不到；把导流翼调回正确档即可，无惩罚。
  - 过去态站进坞底仰头 → 可见取得台的轮廓，但过去态根本没有上升气流（§2.4 #2），这是"反向可读"的提示：台子在过去态更清楚地浮在半空。
  - R06 落坑 → 扣 1 血 + 复位到西段平台。
  - R10 落盐浆 → 扣 1 血 + 复位到起点平台，且**不消耗机关档位**。
- **是否门禁**：是（R10，主脉；W14→W15 的世界连接同挂 `PG`）。

### 3.2 `VC` 时间切换（每区必用）
- **应用房间**：R02 / R03 / R05 / R06 / R08 / R10 / R11 / R15
- **设计意图**：本区把 `VC` 当作"改地面高度"的工具——8 处切换点中 6 处会改变脚下地面高度，是本作最早让玩家意识到"切时代 = 换个高度的地面"的区域。
- **判定几何**：全 8 处切换点都留出 ≥96×160 的两态皆空区（R02 的高台边、R08 的骨梁两端、R10 的起点平台、R11 的桅顶）。
- **失败反馈**：站进盐壳断面切过去（现在→过去地面上升 240）→ 卡墙原子拒绝 + 提示，不扣血。这是本区最常见的一次拒绝，也是"卡墙"规则最直观的一次复训。
- **是否门禁**：是（#1 主脉）。

### 3.3 `PW` 凤凰蹬墙（准入 + 复用）
- **应用房间**：R01（准入反向）、R07（盐柱）、R09（炭架）
- **设计意图**：`PW` 的首次"离开一整个区"发生在 W12 的最后一步——玩家在井底取 `PW`、沿井壁升到井口、打完担山傀、从 R20 东檐出井，纵向落差**全部在 W12 侧完成**，本区只接一个落点。本区内 R07 的 5 根盐柱与 R09 的炭架用同一套"可蹬材质"（统一标签，全章一致），给玩家连续的蹬墙节奏，但**不再承担任何纵向主路**。
- **判定几何**：盐柱间距 220（相向墙），柱高 208（一次上蹬 620 × 0.34 s ≈ 210）。
- **失败反馈**：蹬空落回地面，不扣血。
- **是否门禁**：否（本区内均为省时路线）。

### 3.4 `PA` 凤凰空中冲刺（复用）
- **应用房间**：R04（断桅之间）、R11（桅顶最后一段）
- **设计意图**：断桅掩体之间的 190px 空档用 `PA` 平飞段穿过，是中段战斗的机动工具。

### 3.5 `P2` 凤凰二段跳（复用）

- **是否门禁**：否。

### 3.6 `DS` 龙鳞耐热（尚未获得的高处钩子，第 5 章后段）
- **应用房间**：R10（盐浆底部的**熔岩渗口**）
- **设计意图**：R10 缺口的盐浆底下有 2 处熔岩渗口（可见橙色微光但不可触及，落在盐浆上只会扣 1 血被复位）。取得 `DS` 后回访可从渗口下去，进入一条 1 房深的小窟（本文件不实现，留给 W16 的 `DS` 教学做"回访钩子"）。
- **是否门禁**：否（可见不可达）。

### 3.7 `DT` 龙尾破壁（尚未获得，第 6 章）

### 5.2 配置原则

- **威胁类型搭配**：
  - R02（盐蜮 ×3）：单类型群 + 环境（E-06 三处塌陷）。破解：切过去涉水，盐蜮在过去会退回壳内（过去态无盐蜮 → 本房过去态只剩 E-06 消失、地形平坦）。**本房是本区唯一的"纯教学战斗"，允许零伤通过。**
  - R04（熔壳蟹 ×3 + 断桅掩体）：正面免伤的敌人 + 可蹬掩体。破解：`PW` 蹬桅翻身到侧后，或用 `PA` 从桅侧穿出。
  - R07（盐蜮 ×2 + 烬帆手 ×2）：近战 + 远程混合。破解：先借盐柱掩体接近烬帆手；盐蜮被盐柱卡住（盐蜮不会绕柱）。
  - R09（烬帆手 ×1 + 盐尘蛾 ×2）：飞行 + 远程双层压制。破解：盐尘蛾三段冲后必须下降到 y=600 以下 → 在下降窗口用重击。
- **地形与敌人的咬合**：本区地形让**熔壳蟹变强**（盐壳高台给它天然的仰冲角度）、让**盐蜮变弱**（盐壳断层会卡住它的钻地动画 0.6s）。反过来，地形让 `PG` 变强——滑翔中攻击能保持水平速度，是对付烬帆手的正解。
- **禁止走廊堆怪**：单房间敌人上限 4（R07 为纯怪峰值 4；R04／R09 因各含 1 组静态地刺，实体数同为 4，但可击杀数分别为 3／3）；连续战斗房间上限 3——本区战斗房 R02／R04／R07／R09 之间各隔至少 1 个非战斗房（R03／R06／R08），不构成走廊。
- **v1.1 增补口径**：E-07／E-08 属「静态地刺」新增类（无时间预警、只靠视觉可读性），与既有「环境危害」（区域型/一次性塌陷的 E-06 盐壳裂口）**不同类**；两者不占 §7.1 的杂兵分摊、不计入「连续战斗房」（见总控 §7.4）。

- **为何不可杀**：盐蜮群是**三灵同源的海岸滤食者**——它们不是"敌人"，而是岸线退去后聚在最后一洼盐水里的活体盐层。它们没有可被攻击的个体（打散后 2 s 内重新聚成一片），所以没有血条；世界观上它们是"海岸的皮肤"，删除它们等于删除这一段岸。
- **是否是通行条件**：是主线（R08 是主脉第 8 房）。过去态路线真实可走（干骨梁上层，脊背宽 96 > 角色宽 24，两处高差 140 < 单跳 180）。
- **可读性（3 秒内明白"这不是敌人"）**：① 形态——一片缓慢起伏的灰白盐壳，没有头、没有朝向、没有攻击动作；② 光照——它表面有细密的虹彩反光（盐结晶），与杂兵的红眼高光完全不同；③ 音效——低沉的沙沙声（像退潮），不是战斗音乐；④ 切时代反应——切到过去它整片消失，切回来它整片重现，这个"开关式"反应本身就是最强的提示。HUD 不显示血条，攻击它只溅起盐末。

### 7.2 流程位置

- **章节位置**：第 5 章第 1 区，从 W12 R20「东檐出井」高位落岸进入，是 `PW` 之后的第一段"横向岸线"。

- **离开路径**：R10 东侧 → N-2 → W15 塔基。
- **回访价值**：
  1. 持 `DS` 后可下 R10 盐浆底的 2 处熔岩渗口（新增视野与一条 1 房深小窟，留给 W16 的 `DS` 教学延伸）。
  2. 持 `DT` 后可破 R15 后壁龙骨薄板，打通 R15→R14 的短径（省 3 房）。
  3. N-3 塔顶风廊本身就是永久快线，`PG` 后在 ch5 内部往返只需 1 次滑翔。

### 7.3 连通性自查

- 房间可达性：主脉 R01→R10 全通（`PG` 在 R05 取得，R06 自验证，R10 门）；支线 R11（过去爬桅）、R12（过去浮舟横梁）、R13（`PG` 上升气流）、R14（N 口下沉）、R15（N 口下沉）、R16（N 口下沉）全部可达。**无不可达房间。**
- 单向陷阱：
  - R11 是"过去爬上、现在落地"的单程上行，回程有现在态木斗下垂绳（可爬下）→ 不构成单向陷阱。
  - R14 是精怪战场，战期锁门；战后两门开。**开战前可退出**，不构成不可逆。
  - R10 落点平台（x=5488—5632）到 W15 只有一条路，但落点平台亦可通过 N-3 高空口返回 R09 方向（站台上切过去，过去态残梁在 x=5148 处断开，需 `PG` 反向滑 340px）→ 无死角。
