## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：齿轮场是被删掉的历法的机器间，心湖是这台机器唯一的读数窗——你要在"还在转的过去"里把三段被拆开的记录重新登记成可追责的证据，才有资格推开明日之门；这是全作唯一一次"旧能力变强"，而它变强的方式是**让你同时看两边**，不是让你走得更远。
- **视觉母题**：①渐开线齿廓（铜齿、断齿、卡在齿间的壳）；②湿牛皮纸与纸本卷闸；③静水倒影（湖面同时映出两态）。
- **色彩基调**：过去 `#202849` 底 + 赭褐地形 `#BC8C64`；现在 `#142032` 底 + 冷灰地形 `#657987`；强调色铜齿 `#C8A24A`、静水 `#7A8FA6`。（对齐 [美术圣经](../art/art-bible.md) §2.6，不新增色相。）
- **情绪曲线**：进入——被机械尺寸压住，不知道自己站在谁的计时器里；中段——心湖倒影里看见自己走过的八章，第一次"同时看两边"；离开——仪式房安静到能听见自己呼吸，明日之门只是一框静水。

### 1.2 关卡结构

- **主脉（7 段 8 房）**：`R01 西闸口 → R02 齿槽外道 → R05 纸本梯井 → R06 湖岸南沿 → R07 心湖 → R08 登记厅 → R09 裁决厅 → R10 明日之门前庭`（→ 东出 W25）。
- **环（1 条，与外环齿轮对应）**：`R02 → R03 酸壳齿井 → R04 外环南廊 → R16 南环残台 → R06`。环与主脉在 R02 / R05→R06 两处叠合；环的功能是让"上不去湖岸"的现在态玩家有活路可走，同时在 R03 藏 `DB` 蚀壳（凶骨）与 R16 的齿轮平台（回到 R06 的唯一上升手段）。
- **支脉（3 条，均为死路，尽头给东西）**：
  1. `R06 → R13 齿轴东壁 → R14 东壁齿廊`：尽头战技残篇·第八篇 + 精英「验封门卫」；R13 是双刻场景③（回访型）。
  2. `R07 → R15 北沿齿轮台`：高处俯瞰全湖，叙事物 + 地图残页。
  3. `R01 → R12 钟道前厅 → R11 旧总钟道口`：`ENDGAME` 进度门的里侧前厅，碑文「此门自内而开」在此对读。
- **结构类型**：**单环 + 3 支脉**。理由：齿轮场的通行逻辑是"绕环一圈回到轴心"，环是几何必然，不是装饰；不再加第二条环，因为第二条环会让"上不去湖岸"这个核心失败状态失去唯一解，双时代差异就退化成可选装饰。

### 2.3 竖向设计

- **最大单房间落差**：880（R02 齿槽斜坡、R05 纸本梯井、R06 湖岸拱顶、R10 前庭）。
- **最大跨房连续落差**：1760（R07 湖面 y=720 → R03 井底 y=3200）。
- **贯穿全高的地标**：R07 心湖。它的穹顶是本区唯一一条不断裂的垂直参照线；玩家在 R02 / R05 / R13 / R16 任一房间的齿缝里都能看见湖面反光，反光在**过去态偏亮、现在态偏暗**——这是玩家读懂"现在是哪个时代"的第一手势。

## 3. 探索技能应用点

本区为第 8 章，玩家持有全部 8 项能力（`P2` `QS` `PA` `PW` `PG` `DS` `DT` `DB`）+ `VC`，并在本区取得 `VC@双刻`。九张卡中，`VC` 与 `双刻` 是主脉必需，其余七项均为"让路线变短/变稳"的复用，**不设能力门**（总控 §5：本区能力门为空）。

### 3.1 `VC@双刻`（质变 · 全作唯一一次能力变强）

- **应用房间**：R07（取得）／R01 东缘（边界教学）／R08、R09、R13（三个解谜场景）。
- **设计意图**：把"时间切换"从**位移工具**升格为**判读工具**。终局的 Boss 二阶段会强制换时代，双刻让玩家第一次能"同时看两边"——它交付的是视野，不是脚程。
- **判定几何**：无几何判定。双刻是**渲染层 + 可读层**：`dual_scribed = true` 时，当前时代的渲染管线叠加另一时代的地形轮廓（对比度 28%、无光照、无碰撞），并对 `interactable`、`device_level`、`pickup` 三类对象输出可读轮廓。
- **失败反馈**：无失败态。它没有输入、没有冷却、不消耗资源，切换时代时**不改变任何现有规则**（卡墙拒绝、无落点扣 1 血全部沿用 [feature-time-switch.md](../feature-time-switch.md)）。
- **是否门禁**：**否**。总控 §5 末行写死：「结局主线不需要 `双刻`」。它的唯一后果是真相补遗与尾声旁白完整度。

#### 3.1.1 双刻做什么 / 双刻不做什么（授权边界，写死）

**双刻做什么（4 条，且只有这 4 条）**

1. **对侧地形同时显形**：不切换时代，另一时代的地形以虚影叠加显形，用于判断"该切到哪一边"。虚影是纯渲染层，无碰撞、无光照、不受角色物理影响。
2. **对侧交互物轮廓可读**：机关档位、可拾物、碑文这类交互物在虚影中输出轮廓与档位标记——**只在取得双刻后可读**；未取得时对侧只有静态残痕（不含状态）。
3. **两态文字可合读**：同一处刻辞在两态各存一半笔画时，双刻让两侧笔迹叠合成立（W25 秘境门的"叠刻字"即此用途）。
4. **读相位与周期**：像齿轮相位这种"只在一个时代变化"的量，双刻让玩家不切换就读到对侧当前值。

**双刻不做什么（3 条硬禁止，等同总控 §8.2）**

1. **不可踩对侧虚影平台**：虚影无碰撞，站上去直接坠落（本区唯一实测点 = R01 东缘齿孔虚影，坠落回 R01 地面，不扣血、不提示）。
2. **不可借虚影穿墙**：虚影只是渲染层，不改变任何实体碰撞。R01 东缘齿孔的虚影后面就是湖面，**看得见、进不去**。
3. **不可在虚影上停留或起跳**：虚影不提供落脚、蹬墙、滑翔锚点，也不延长跳跃距离与冲刺距离。

> **实现口径**：`dual_scribed` 只影响 `CanvasItem.visible` 与 shader 参数，**不得**进入任何碰撞查询、`_has_support` 判定或 `PhysicsBody2D` 层。任何以"双刻可过"为前提的通路视为规格错误，必须退回。

## 6. 精灵、精怪与 BOSS

### 6.0 精灵（环境型生灵）

| 编号 | 名称 | 所在房间 | 单时代归属 | 阻挡方式 | 驱散/安抚条件 | 绕行代价 |
| --- | --- | --- | --- | --- | --- | --- |
| SPL-01 | 刻齿灵 | R06 北口 | **现在态独占** | 现在态盘踞湖岸北口，封口净宽 260（角色可通过宽 24，被它的身位 180 完全堵死） | ①**切至过去**——过去态它不存在（齿轮自己在转，不需要替轴），北口是木桥；②现在态完成"替轴复位"交互（需双刻先读出替轴位置，见 §3.1.2 场景③） | 过去态路线多绕 R06 西段 30 s，且有三只抄录傀巡游 |

- **为何不可杀**：它是三灵同源的**环境型生灵**——一具"替未转的齿轮咬住轴"的活替身。它没有血条，因为它在世界观里不是一个个体，而是**这段机械停摆时长出来的东西**：删稿相的删稿动作让齿轮停了，停摆本身凝成了它。打它等于打自己的影子，游戏性上也不该给血条（给了就变成 Boss，逃逸路线消失）。
- **是否是通行条件**：**是（主脉）**。现在态的湖岸北口是 R07 的唯一常规入口；另一时代的路线（过去态木桥 + 浅水）**真实可走**，不是假绕行——它慢、有敌人，但一定通。
- **可读性（3 秒内明白"这不是敌人"）**：①**形态**——它没有攻击动作，只有"咬住"这一个姿态，四条齿状附肢固定在轴上；②**光照**——它身上没有敌人共用的红色轮廓光，而是铜齿的 `#C8A24A` 自发光；③**音效**——它发出的是**齿轮空转的咔哒声**，不是敌吼；④**切时代时的反应**——切到过去它**整体消失**（不是淡出、不是逃跑），这是玩家最关键的一条线索：能"不存在"的东西不是敌人。

### 6.1 精怪（可战斗精英，锁门）

**本区无精怪。** 理由（必须写清，防止后续被"补一个精怪"）：总控 §7.1 第 8 章精怪 1 场，已在 `data/world-25.json` 落到 W23 八门汇流厅（`encounters.elite_guard: 1`），本区与 W25 均记 0；总控同时规定"单区 0—1 场、不与该区守印者战场叠房间"。本区无 Boss，若再加一场精怪，第 8 章会变成"三连强制战"，与终局"站在平地上做裁定"的节奏直接冲突。

### 6.2 无 BOSS 说明（总控明令）

**本区无 Boss，且不得虚构。** 本区承载的是**仪式**而非战斗，三间仪式房（R08 / R09 / R10）已独立成房并计入 17 间：

| 房间 | 仪式内容 | 为何必须是"仪式房"而不是战场 |
| --- | --- | --- |
| R08 登记厅 | 三层证据台账登记（原件验封 → 公开副本登记 → 隐私授权**签署**） | 登记是**玩家自己做**的动作（读、比对、按下、长按确认），中间插战斗会把"追责"变成"过关"。第 3 层是一段**交互**（阅读授权条款 3 段 → 确认 → 生成授权凭据，约 15 s，可中断续读），不是补录台、不是拾取物。置位 `FINAL_DOOR`（第 2 层完成）+ `ENDGAME`（第 3 层完成）；缺第 3 层则 `ENDGAME` 不置位，但 `FINAL_DOOR` 已开故不软锁 |
| R09 裁决厅 | 三面对读席：原告 / 被告 / 第三人的证词互证（两态各存一半） | 这是全作唯一一次让玩家**同时听三方说话**，任何敌人在场都会抢走注意力 |
| R10 明日之门前庭 | 静水门框 + 灯龛。门前不设门扇，只有一框静水 | 终局的门不该有守卫——删稿相在 W25，等你走进去 |

> 与前作的对照写清：W12 / W19 的守印者战场是"战期锁门、战后开为通路"；本区三间**全程不锁门、不生成战斗、无削韧条**。`w24` 的 `boss` 字段为 `null`，`elite_guard` 为空数组——这条是硬校验项。
