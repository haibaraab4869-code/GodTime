## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：一座三层的档案楼，楼里有一口井用来"寄信"——把写着名字的纸投进去，司历就会把它从名册上划掉。**过去有人在往里投信，现在井口被石板封住了：不是因为井坏了，是因为再也没有人需要被划掉了。**
- **视觉母题**：`卷宗架`（过去全开、现在闭锁，架门的缝是唯一的刻度）、`封板`（一块盖住井口的青石板，四角有四个撬痕，说明有人试过打开）、`墨线`（抄录台光路投出的直线，过去横穿东廊，现在断在半途）。
- **色彩基调**：主色 现在 `#142032` / 过去 `#202849`；地形 现在 `#657987` / 过去 `#BC8C64`；强调色 `#C9A24A` 只给墨线与封板撬痕。
- **情绪曲线**：进入——从 W02 的闹市钻进一条又高又窄的书廊，声音被吸掉（本区混响最短）；中段——沿西廊一路爬到顶层，越往上越安静，到井口时只剩纸的声音；转折——把信投进井里才知道井底是封的，第一次"往下"掉进一个本该进不去的地方；离开——从封板下出来，穿过墓园外的南廊，回到有光的东廊，第一次觉得"东边有光"是件好事。

### 1.2 关卡结构

- **主脉（一个大螺旋）**：南入口 R15 → R11（爬）→ R06（爬）→ R01（顶层）→ R02 → R03（井口）→ **坠井** → R13（封板下）→ R14 → R10（爬）→ 东出口。
  这条主脉的骨架是"**升到顶再掉到底，再爬到中层**"：先 1376px 的连续上行（本作最长的单段落差爬升之一），再用一次 1056px 的坠落释放张力，最后 480px 收束。上行段的每一级台阶都在教"这里的垂直结构是可读的"，所以坠落时玩家不会觉得被骗。
- **支脉（4 条）**：
  1. **R04 抄录台（光路）**：顶层东侧的机关房，三层光路辨伪，正确档位把光打到 R10 的接收端，开启 R10 的一段附墙梯（省 1 房间）。非门禁。
  2. **R05 北窗阁**：R04 的死路延伸，北窗高梁 y=176 是 `P2` 钩子（可见不可达）。第 1 章无法取。
  3. **R09 寄信台**：只从 R10 进的死路，放「未寄之信」。**回报在出口侧**（规律 7）：玩家是从 R10 进来的，读完原路返回。
  4. **西侧暗门（通 W26 无姓者墓园）**：从 R15 西墙进入；过去态封砖后是拱洞，现在态是实心墙。墓园本体已于 v1.3 独立成区，本区只留这道门（见 [W26](w26-wuxingzhe-muyuan.md)）。
- **结构类型**：**单螺旋 + 四条死路支脉**。选它的理由：主题大区（14—18 房间）必须有全高地标，而本区的地标是一口**竖井**——所有房间都要围着它排。螺旋是最省房间的"围井"排法：外圈三层绕井一圈，井在正中偏东。
- **节奏节拍**（5 拍，合计约 620s）：

| 节拍 | 房间 | 压力类型 | 内容 | 预计时长 |
| --- | --- | --- | --- | --- |
| ① 入廊 | R15—R11 | 战斗（轻） | 3 只巡簿兵 + 第一段 480px 爬升 | 90s |
| ② 爬顶 | R06—R01 | 喘息 + 机关 | 灯龛、576px 爬升、两块可读碑 | 110s |
| ③ 井口 | R02—R03 | 叙事 → 精怪 | 卷宗架对照、删名吏锁门战 | 150s |

### 1.3 与参考作的关系（合规声明）

| 借鉴的规律（编号见参考 README） | 本项目变体 | 与原型的差异点 |
| --- | --- | --- |
| 规律 1 · 形状即玩法 | 1.1:1 的近正方被切成四层横带（544/576/480/320），靠一条 1056 高的竖井把它们串起来；**比例本身不提供玩法，竖井才提供**，所以本区的宽高比只是外框 | 参考的近正方区（真菌荒地 1.08:1）靠"四向铺开 + 弹跳平台"制造立体；本区靠"**一口井**"制造立体，横向只有一条外圈——同一比例，两种完全不同的组织方式 |
| 规律 4 · 超大区必须有全高地标 | 地标是**寄信井**（x 1180—1408，y 544—1600，高 1056 = 本区净高的 55%）。它不是塔而是**井**：玩家在 R13（最底）抬头能看到井口漏下的光柱，在 R03（顶层）低头能看到同一束光的末端 | 参考的地标是"往上戳"的（塔、广场、钟楼）；本区是"往下陷"的，地标的方向反过来——因为本区讲的是"被删掉的东西都在下面" |
| 规律 7 · 迷宫靠撤信息 | 本区**不做迷宫**，但做一次"信息撤除"：现在态的卷宗架全部闭锁，玩家看不到架后的结构；过去态架全开，能看见每一层架的背面。所以**读图这件事本身要切时代**——地图不是被拿走了，是被锁在另一个时代里 | 参考撤的是"地图道具"；本区撤的是"**可读性**"：现在态你看得见房间但看不懂房间，过去态你看得懂但走不了那条路（因为井口未封，掉下去就回不来） |
| 规律 8 · 风格割裂 | 内嵌暗区「无姓者墓园」做**局部割裂**：进入后 UI 边框的赭金线消失、所有交互提示变成哑光灰，但**不换整体色板**（避免玩家以为进了新区域） | 参考的割裂是整区换色；本区只换"UI 的材质"，因为墓园仍是同一座城的一部分，只是"没有被归档" |

**地形相似度自查**：与真菌荒地（1.08:1）比，拓扑 8/40、轮廓 3/30、母题 3/30，合计 **14/100**（与总控 §8.3 表一致）。三项判据中「形状」接近（1.1 vs 1.08）但「入口数」（3 vs 四向铺开）与「主脉走向」（单螺旋 vs 四向）两项均不同，满足"改写至少两项"。

### 2.3 竖向设计

- **最大连续落差 1376**（R15 地面 1920 → R01 地面 544），分 12 级台阶，每级 ≤160；**最大单次坠落 1056**（R03 井口 544 → R13 井底 1600），无伤害。
- **全高地标：寄信井光井**。定位方式三档：
  - R15/R13（最底层 y≈1800/1550）：抬头可见井口漏下的**一束光柱**，直径约 96px，是全区唯一的竖向光源；
  - R08（中段）：光柱从头顶穿过，四周是井壁的石刻凸台（6 处，间距 160）；
  - R03（顶层）：光柱从脚下的井口往下消失，封板（现在态）把它截断在 1120。
- 攀爬链（全部 ≤160）：
  - R15 1920 → 1792 → 1664 → 1600（进 R11）
  - R11 1600 → 1488 → 1376 → 1264 → 1152 → 1120（进 R06）
  - R06 1120 → 1008 → 896 → 784 → 672 → 560 → 544（进 R01）
  - R14 1600 → 1488 → 1376 → 1264 → 1152 → 1120（进 R10）
- 井内（过去态）石刻凸台：704 / 864 / 1024 / 1184 / 1344 / **1400（龛台）**，间距 160，全部可上下。

## 3. 探索技能应用点

### 3.1 `VC` · 跨时代穿墙（首次 · 教学三连第二环）

- **应用房间**：R03 → R08 → R13。
- **设计意图**：教第二件事——**切时可以把"墙"变成"门"**。W01 教的是"切时会换掉脚下的地"，本区教的是"切时能把你送进一个现在进不去的地方"。这两件事合起来，玩家才真正理解"两态是两套碰撞"。
- **判定几何**：
  1. 玩家在过去态从 R03 的井口（x 1180—1408，y=544）沿 6 处凸台下到 **龛台 (1180—1300, y=1400)**，站在 (1240, 1360—1400)；

### 5.2 配置原则

- **威胁类型搭配**：
  - R07「近战 + 远程」：纸人 2 + 抄手 2，抄手站在书吏案后（x 820），案台高 176。破解 = 先跳上案台打抄手。**教学点：远程敌人要先处理，且它总是站在高处。**
  - R11「单类型群 + 攀爬场」：巡簿兵 3 在 480 高的攀爬房里，玩家在爬台阶时被打会掉下去。破解 = 先在一层清完再爬。**教学点：攀爬房里不要带着敌人爬。**
  - R13「单类型群 + 低天花」：巡簿兵 2 在封板下，头顶是卷宗落堆（净高只有 160）。**教学点：低天花房里跳跃会撞头，改用横向走位。**
  - R16（墓园）「单类型群 + 单时代」：纸人 2 **只在过去态**。玩家切到现在，敌人归零，但墓园的门也消失了——**这就是本区最核心的一次权衡：安全与可读性只能二选一。**
- **地形让敌人变强/变弱**：
  - 变弱：R11 的 160 级台阶让巡簿兵（地面近战）必须一级一级跳上来，玩家有 3 秒的免费输出窗口。
  - 变强：R13 的 160 净高让玩家的跳跃失效，巡簿兵的平推变得难躲。
- **密度与节流**：单房间 ≤4（R07 = 4，上限）；连续战斗房 = 3（R11→R06 空→R07，中间隔一间灯龛房，实际连续 2 间）；R08 是精怪战场（锁门），打完给 R13 一整间无敌人的坠落段喘息。
- **单时代敌人**：R16 的纸人只在过去态——这是全区唯一"敌人跟着时代走"的实例，也是墓园"只在过去存在"的叙事落地。

- **在章节主线中的位置**：第 1 章第 3 区（W02 之后的三角环东侧环边），必经。也可被玩家整段跳过（W02 直连 W04）——总控 §4 明确"三角环两条路都通 Boss 门"，本区是**可跳过的内容区**，但跳过会少 `VC` 的第二次教学，第 2 章的 `QS` 回环也就找不到入口。
- **首次到达路径**：W02 北口 → R15（南入口）。**进入时默认时代 = 过去**（本区是"读"的区，过去才是记录完整的时代；且入口房间 D 分区两态一致，切时代的教学从 R02 才开始）。
- **离开路径**：东 → W04（R10 东口）。
- **回访价值**（至少 1 条）：
  1. `P2` 后回 R05 取北窗信匣（叙事）。
  2. `QS` 后（第 2 章）从西北口 R01 直通 W06，本区成为"第 2 章回第 1 章"的陆路入口。
  3. `DT` 后（第 6 章）城簿库的实心墙可破，打通 R12—R13，让"封板下"不再依赖井——这是本区唯一一处后期地形解放。

### 7.3 连通性自查

- **所有房间从任一入口可达**：15 间全部可达。R05 只从 R04 进（死路支脉）；R09 只从 R10 进（死路支脉）；R12 只从 R11 进（死路支脉）。全部原路可返。西暗门通向独立区 W26。
- **不存在"进入后无法离开"**：
  - R08 精怪锁门是**双向锁**，打完才开；战败回 R06 灯龛，不卡场。
  - 最长的一次"回不来"是坠井：从 R03 掉到 R13 后，来路（井口）在过去态可爬回（6 处凸台，间距 160），**不是单向陷阱**。已实测最短回程 = R13→R14→R10→(光路附墙梯或 R09→R10→R14 折返)→东出口。
  - 过去态在井筒内切换会被落堆拒绝，但向东走出 x>1440 即可正常切换，无软锁。
- **无落点分支的边界**：井筒内存在"切时无落点"的可能（在井口正上方切 → 落到封板顶面 1120，不算无落点；在封板内部切 → 拒绝）。**主线不依赖任何扣血分支**：穿墙教学的落点是卷宗落堆顶面 1400，是实体平台。
