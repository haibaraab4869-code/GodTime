## 4. 约定

- **共边**：两区共享一条世界边，门点两侧世界坐标完全一致；玩家穿门即进邻区，无过渡。
- **跨空连接**：`loop` 类跨章回环（7 条，含 `ENDGAME`）。两端在世界图上不相邻，门开在各自外侧，靠过渡走廊／升降／剧情门表现，**不参与共边校验**。
- `pos` 为**区局部坐标**；世界点 = `canvas_origin + pos`。门点必落在本区边框上，且落在所连房间的朝向面内（取房间矩形中心投影后夹进共边区间）。
- 引擎侧：跨区镜头用 `canvas_origin` 直接换算；同区内房间坐标仍是局部的，不要与 `canvas_origin` 重复相加。
- **`×N` 与复合标签**：`×N` 表示两区之间的门记录条数（`links` 计数，正常为 2 = 双向各一条）。出现 `main+loop` **不代表两道门**，只是两端 `kind` 标注不一致时的复合显示（W02↔W12、W04↔W24 属此类：一端按主干写 `main`、另一端按回环写 `loop`）。曾经唯一真正双门的一对是 **W14↔W15 赤潮观测塔**（主门 R10↔R01 贴地过闸 + 回环门 R10↔R06 塔顶风廊），v1.3 收口时已**折叠为单条 `E15`**：运行时一条区对只能承载一条边（`[[a,b]]` 索引对 + `connections` 逐条对齐），同对双门会撞索引。塔顶回落改为 M3 的区内风井交互，**不要给同一对区加第二条边**。
