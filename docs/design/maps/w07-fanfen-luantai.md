## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：一份写着「已焚，无异议」的同意书 —— 正面是公文，背面是四百二十个手印。这座台子存在的唯一理由，是让签字的人以为自己是自愿的。
- **视觉母题**：`翼板`（斜向外张的木石翼面，全图唯一的方向结构）、`灯羽`（过去态的暖光点，现在态全部熄灭留下空钩）、`赭金`（唯一一种在两地都亮着的颜色，因为它是自己的光而不是反射）。
- **色彩基调**：**本区整体跳出色板**（规律 8 允许的风格割裂）：主色 底 `#241A13`（深赭黑，两态共用）；辅色 过去 `#A8763F`（暖赭）／现在 `#7A6350`（灰赭）；强调色 `#D9A441`（赭金，只出现在灯羽、同意书纸面、翼板棱线上）。**与 art-bible §2.6 的两态蓝底规则冲突是刻意的**，判据是总控 §8 第 8 条与第 14 条：秘境由「叙事状态」驱动割裂，不受常规色板约束。
- **情绪曲线**：进入 —— 暖。玩家刚从燃羽与冷灰里出来，这里的赭金会让他以为「终于有个能喘气的地方」；中段 —— 空。灯羽全灭、羽笼全空、没有敌人也没有人，暖色只剩下自己发出的那点光；离开 —— 手印。读完整面手印后走回西北门，暖色变成一种不适。

### 2.5 平台挑战段：断檐外沿「檐脊跳」（v1.1 新增 · 可选支线 · 4 段）

**定位**：本区唯一的可选平台挑战段，规范见总控 **§7.5**。它是既有主线「现在从断檐起跳上木架顶」的**反向外沿**——同一根断檐往西多走四段极窄檐脊，尽头是同意书**背面的第二段**。**不新增房间、不改 `rect` / `floor_y` / `links` / `world_links` / `size`**：4 处檐脊全部挂在 R05 覆板（y440）下方的净空里（x 512—928、y 552—588），房间数仍为 7。

**为什么这里可以有挑战段（而其他秘境不行）**：总控 §7.5 第 7 条禁止把挑战段放进秘境，**唯一例外是 W07**——因为本区**零敌人、零死亡、失败落软垫零扣血**，挑战段不会把"秘境撤掉敌意"这条设定变成一句空话。W13／W18／W22 的"不考操作"条款一条未动。

**双时代口径（保留既有设定，逐字不改）**：**同意书背面只在过去可读，必须从现在的断檐起跳。** 现在态断檐（y520）存在、过去态该处是仪门门扇实体（x1040—1100、y440—640），段 1 的起跳点**在过去态根本不存在**，所以整段**只能在现在态起跳**；而 4 处檐脊本身两态皆实心（它们是檐脊，不是门扇），因此**可以在「檐脊丁」上按 Tab 切到过去**，读那一面手印之后的逐户签押。这是本区「现在起跳 → 过去读」的第二次应用，与主线 J-02 同一套肌肉记忆。

## 3. 探索技能应用点

### 3.1 `VC` 时间切换（本区的**核心机制**，全图以它为唯一解谜手段）

- **应用房间**：R05（木架顶，切换读背面）、R04（灰笼井，切换上下行）、R02（上层回廊，切换横穿）、R07（底厅，切换上行）。
- **设计意图**：本区是全作唯一「切时代 = 翻到纸的背面」的地方。前 6 个区（W01—W06）教的是「切时代能过去」，本区教的是**「同一个位置，两个时代给出两份证词」**——这是第 8 章 `VC@双刻`（只交付信息）的**前兆教学**：玩家第一次体验到「信息本身随时代改变」，而不是「路随时代改变」。
- **判定几何**：木架顶 y=560、覆板 y=440，净空 **120px**（角色高 92，余 28）——过去态站在木架顶按 Tab 不会被判卡墙；缺口 x=980–1040 宽 60，净空同样 120，角色可侧身穿入。这两条已按 `feature-time-switch.md` §2 的 24×40 碰撞体与 92 极限高逐项验算。
- **失败反馈**：在现在态断檐（y=520）按 Tab 切到过去 → 过去态该位置有门扇顶部（y=440–640 的实体），角色会与门扇重叠 → **原子拒绝**并提示「当前位置无法使用该能力」，不扣血、不位移。这是本区唯一会触发拒绝的典型位置，且它恰好就是解谜点——玩家会在三次拒绝后自己意识到「要先跳过去再切」。
- **是否门禁**：**是**（本区所有通行与所有阅读都依赖它）。

### 3.2 `P2` 凤凰二段跳（**入场资格** + 一处支路）

- **应用房间**：全区（入场）；R03 檐上二层。
- **设计意图**：`P2` 在本区的职能是**门票**而不是工具——这是总控 §5 给它的「回访捷径」定位（W06 取得 → W06→W07 秘境入口）。秘境内部只用它一次，且那次是可选收集。
- **判定几何**：
  - 入场：W06 的 R18 东墙门洞外是 260px 宽的断梁口（断梁之间无落脚），单跳水平 300 但落点只有 60px 宽且需越过 96px 高的栏；`P2` 二段可调整落点。
  - 支路：R03 檐面 384 → 檐上二层 160，垂直 **224px**（单跳 180 差 44，`P2` 上限 240 可过）；水平 60。
- **失败反馈**：跳空落回檐面（安全，无伤）；不显示提示，角楼残柱上挂着的空钩（灯羽已被取走）是唯一线索。
- **是否门禁**：入场**是**；支路否。

### 3.3 单跳 + 冲刺（基础）

- **应用房间**：R04（灰笼顶三级 140/140）、R06→R05（木架顶，水平 100 / 落差 -40）、R07（台基 128）。
- **判定几何**：全部 ≤180 高差、≤300 水平，无一处需要冲刺的极限距离；冲刺只用于 R06→R05 起跳后的空中微调（落点宽 160，容错充裕）。

**v1.1 增补 · 挑战段用到的能力（§2.5）**：只用**基础单跳 + 冲刺微调**（4 段落点宽 64、跨度 128—224、高差 ≤68）。**不需要任何能力**——`P2` 只是入场资格（秘境门），`PW` 钩子（§3.4）与挑战段无关。反过来说：**挑战段不得被改成"只有 `P2` 才过"**，否则它就成了能力门而不是挑战（验收项见 §9）。

### 3.4 尚未获得能力的高处钩子（`PW` 蹬墙，第 4 章）

- **应用房间**：R04 灰笼井。
- **判定几何**：R04 井壁两侧各有一段竖直的可蹬石面（过去态的会合台立柱），间距 **160px**；从 832 面蹬墙可逐级上到 y=384 的上层回廊，比现在态笼顶路线少 3 跳。蹬墙面在南壁 x=120–200 与北壁 x=300–380，两态皆存在。

**本区无任何敌人**（杂兵 / 远程 / 飞行 / 环境 / 精英 全为 0）。这是总控 §8 第 8 条「秘境风格割裂」的硬执行：W07 的割裂是「无杂兵」，与 W13 的「无钟无声」、W18 的「无 UI 无文字」、W22 的「纯黑白」并列，四个秘境各自撤掉一种东西——本区撤掉的是**敌意**。

### 5.2 配置原则

- 无敌人，因此无「威胁搭配」可写。替代的压力来源是**高度**：全区 3 层、2 条垂直通道、最大连续落差 896px，玩家在没有敌人的情况下仍需判断「我上得去吗」。
- **为什么不放任何敌人（含环境陷阱）**：本区的解法是「在同一个点上换时代读两份文件」。任何追击型敌人都会逼玩家离开木架顶、打断阅读；任何环境陷阱都会让「失误 = 扣血」，把叙事节奏变成动作节奏。总控 §7 给秘境的杂兵上限是 2—3 组，本区取 0 并显式声明，属**低于上限**的合规选择。
- **区分声明（v1.1 必须写清）**：本区的 **4 段檐脊是「平台挑战」（§2.5，失败落软垫、零死亡、零扣血），不是「危险地形」（地刺，§7.4）**。二者在总控里分属**两套不同规范、互不冲突**：平台挑战段考的是"要不要多走一趟"，失败只损失时间；危险地形考的是"看见没看见"，失败扣 1 血。本区**地刺 0 处**（秘境禁区），因此"秘境无敌人、不考扣血"这条设定**完全没有被 §2.5 触碰**——它撤掉的仍然是**敌意与惩罚**，加进来的只是**一段自愿的跳跃精度**。
- **与守印者/精怪的关系**：本区无 Boss、无精怪。同章的两场精怪由 W05（薪偶·守垛人）与 W06（守药偶·铁箍）承担，两场都与本区无关、不共用战场。

### 8.4 状态与存档

- **需持久化旗标（`flags`）**：
  - `w07_checkpoint_lit` — 本区**不设灯龛**（秘境无存档点，沿用「秘境只在入口前存档」的惯例；玩家进区前在 W06 的 R01 灯龛存档）
  - `w07_item_J01` … `w07_item_J11` — 11 件奖励
  - `w07_item_J12` — 挑战段回报（同意书·背面第二段，v1.1）
  - `w07_pf_eave_step` — 挑战段当前已通过的段号 0—4（失败只回退到该段起点，不整段归零）
  - `w07_consent_back_read` — 同意书背面是否已读（驱动 `D1`）
  - `w07_d1_open` — 吊笼是否已降下
  - `w07_door_w06` — 西北门首次开启
- **`checkpoint` 字段**：本区无灯龛，`checkpoint.room` 指向入口房 R01、坐标 (120,360) 作为**死亡复位点**（不是灯龛，不提供包扎药与机关重试），与 W06 的灯龛区分。
- **重置范围**：死亡后复位到 R01 (120,360)；本区无敌人，无战场重置问题；`w07_consent_back_read` 与 `w07_d1_open` **永久保留**（一次性叙事进度，不因死亡回退）。转图时不保留任何地形临时状态。
