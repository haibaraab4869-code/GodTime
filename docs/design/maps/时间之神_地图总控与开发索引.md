# 时间之神｜全世界地图总控与开发索引

**用途**：制作人排期、关卡设计、叙事、美术、程序、QA共同使用。配套第01—08章分章地图文档；每个 M 编号对应一个独立可制作地图场景，章节文档内包含该地图的出口、门槛、剧情、可交互、隐藏内容与验收。版本：扩展设计草案 v1.0；原始依据：《时间之神：类银河恶魔城游戏策划案（设定版）》；以下新地名、角色、事件、时长、地图数量均为本次**创作提案**，不是原案既定事实。

## 一、源案不可破坏约束
- 2D横版、战斗与跳跃并重；开局可免费任意切换过去／现在。切入墙体或无立足点须扣血并安全复位，不能卡死；可站立的封闭空地不能被无故传出。
- 初始：左右移动、跳、攻击、地面冲刺／闪避；凤凰依序二段跳→空中冲刺／闪避→蹬墙。龙只探索：龙鳞耐高温／熔岩；龙尾破指定墙／地板；龙息冻结水／腐蚀指定障碍。麒麟增生命与回血次数，后续强化继续增回血次数。
- 四凶只改变战斗，不能是任何通路钥匙；凶骨／战技残篇／流派变体也不能作门。四套不加点基础流派均可通过每个必经战斗。重要Boss前有存档；探索不能以禁疗制造压力。
- 死亡能力、已获道具与已选流派保留；未花费魂魄掉落，可原处取回。探索奖励优先故事、魂魄、凶骨、残篇与麒麟强化，不能把必经通路藏在战斗配置后。

## 二、完整内容范围与100小时目标（制作目标，非实测保证）
全图48张：每章5张主线图+1张可选隐藏图；8章×6=48。推荐顺序01→08，但回环可并行探索。目标首次完整游玩（主线+支线+隐藏）：104小时；其中主线叙事／首通62小时、支线与隐藏25小时、能力回访及档案17小时，62+25+17=104。纯主线约62小时；如果要声称“至少100小时”，需明确采用“完成主要支线与隐藏探索”的口径，且由实际试玩验证，不能以强制刷怪或空泛文本充数。单次会话建议40—60分钟，存档点间主线距离目标8—15分钟（均为待测调参值）。

## 四、时间与能力门状态机
世界状态 T∈{过去,现在}；时间切换免费、可重复、全地图有效；仅叙事镜头／传送载入的短暂过渡不可操作，恢复后无需冷却。能力标记 P2（二段跳）、PA（空冲）、PW（蹬墙）、QS（麒麟）、DS（龙鳞）、DT（龙尾）、DB（龙息）永久保存；DB含同一能力下“冻水／酸蚀”的场景用途，玩家不需额外收集一种龙息。关键检查顺序：进入可用出口→检查时间态地形→检查已获能力→检查互动目标类型→执行位移／场景变化→检查安全着陆。能力不满足时给可读地形线索，不消耗资源；互动失败不软锁。死亡后复位可破地形的破坏状态按区域首次破坏永久保存；可冻结水在离开地图后复原，冰上玩家切换／融化时优先落到有效安全点，不能形成永久堵路。过去／现在部分水面状态不同，冰只覆盖当前时代且在切换后重新求解。

**能力门最早合法取得**：P2=M09；QS=M10；PA=M16；PW=M22；DS=M28；DT=M34；DB=M40。任何主线出口不得要求其所在章尚未获得的能力；隐藏图允许标记为“晚返”。龙鳞仅消除环境高温／熔岩伤害，不等于战斗减伤；龙尾只能打有统一纹理与反馈的脆化地形；龙息不能代替战斗攻击，也不能烧怪／冻怪。

## 五、剧情总纲与分支闭环
创作前提：主角本为管理万物前后因果的“时衡”，灾变“断刻”后失去时间以外的神权。山海异兽被记录官改写成可被重复祭用的“八荒证词”；记录者不是单一恶神，而是由各地求生者的删改累积成的机器“司历”。每章调查一份“被删除的证词”：城民、丹丘羽民、羽渊引路者、不周背山人、炎海盐民、归墟守墓者、沧海逐潮人、司历自身。主线问题由“谁毁了世界”逐章推进至“谁有权替别人决定被忘记什么”。
- 01：找时间裂痕与第一张伪造的死者名单；证人白螭否认自己曾存在。
- 02：找凤凰羽的去向；丹丘人用焚城换来下一代不被饿死。
- 03：找被拆走的天空航路；引路者夸父之裔被写作叛徒。
- 04：找到不周脊柱里的旧钟；背山人证明神明曾签署牺牲契约。
- 05：查海为何着火；龙族替凡人担下了天火之罪。
- 06：揭开墓城反复“招魂”的人口账；死者愿望不等于生者的代言。
- 07：在息壤海校验所有证词，追溯司历由谁共同塑成。
- 08：玩家在可追溯的证词上作公开裁定；无论结局，过去遭受的苦难不可被一键抹平。
结局分支仅改变叙事裁定与城镇恢复，不封锁真结局在某一四凶、隐藏物或刷魂数量之后；隐藏图提供证据与细节，不将基础结局锁死。具体剧情见各章场景内的证词、人物冲突、反转和尾声。

## 六、地图数据规范与验收
每张场景按 `map_id, chapter, scene_name, era_layouts, ingress[], egress[], gate_expression, spawn_anchor, save_anchor, quest_flags, interactables[], hidden_reward, encounter_profile, reset_policy` 配置。边记录成双向有向边，单向跌落必须有恢复路线；每个时代至少有一处可立足的返回点。章节验收：自动图遍历从M01覆盖48图；去掉所有隐藏节点主线仍可至M47；禁用某四凶/凶骨/战技仍可到达所有主线地图；切换到每张图每个采样点不会卡墙；失去魂魄后可回收；Boss前能恢复正常回血；取得能力前可看见但不能误入后续捷径，取得能力后回环可双向使用。

**开发拆分**：一张地图一个场景文件、一个节点配置、一个剧情事件清单、过去／现在两层碰撞图和一套联调测试；先做M01—M11纵切验证时间门+二段跳+麒麟，再开发余下章节。100小时目标必须由盲测的P50/P75全收集时长复核；若不足，应增加有决策与状态变化的支线，而非放慢移动或提高掉率门槛。
