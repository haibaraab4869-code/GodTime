## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：全作的最后一道地形不是一道向下深开的窟，是一间**空庭**——过去态把它布置成"未删的明日"（干净的、没有灾民的白石地面），现在态把这份理想图压下去、让名单浮上来成为你脚下的地；你要踩着名单走到主审位前，把"承诺"和"凭据"分开，然后裁定公开到什么程度。
- **视觉母题**：①白石判决台（三面无饰、只有一道刻线的直角石）；②刻字名单本身作为地形（字脊、字沟、倒塌的名单梁）；③悬空的投影（过去态的天顶是一整片半透明理想图，像一张还没落笔的宣纸）。
- **色彩基调**：过去 `#202849` 底 + 赭褐 `#BC8C64`，但**整体提亮一档**（承诺的曝光，+12% 亮度）；现在 `#142032` 底 + 冷灰 `#657987`，**整体压暗一档**（凭据的沉，−10% 亮度）。强调色：判词朱 `#A8452F`（只在现在态出现，因为"判"是现在的事）。
- **情绪曲线**：进入——空得让人不敢快走（四周没有可抓的东西）；中段——脚下一路是名字，走过去会听见它们被念出来（音柱）；离开——坐在主审位上，全庭没有人，只有两条可选的落判。落判之后东墙裂出一道门（W29），那扇门后是全作唯一没有时间的地方。

### 1.2 关卡结构

- **主脉（5 房）**：`R01 西阙门 → R02 空庭南道 → R03 灾民名册廊 → R05 主审庭（BOSS）→ R06 判后庭（落判）`，落判后原路返回 R01，西出 W24；或东出 R04 的秘门去 W29。
- **支脉（3 条）**：
  1. `R03 → R04 原告席`：东柱支路，全区唯一的高厅（净高 2480）；原告证词、精英「席守」、三处叠刻之一、以及**落判后开启的秘门（东墙 → W29）**。
  2. `R01 → R07 西空阶`：竖井支路，`PW` 蹬内壁凿痕直上，尽头凶骨 ×1。
  3. `R06 → R08 东阙影壁`：壁画支路，双刻合读的关键一半（叠刻字之一）。
- **暗区通路（跨区）**：`R04 东墙 (3200,3040) → W29 不曾发生的春天 R01 秘境门厅`，门槛 `w25_verdict_sealed`。**这不是本区的房间**——它只是挂在原告席东墙上的一道门，进门即转图。
- **结构类型**：**枝状（一轴三进）**。理由：终局不允许网状。判决庭的语义是"一条道走到主审位前"，任何横向回路都会把"裁定"稀释成"探索"。全区只有一条中轴（x=1600 附近），两侧的支路都是**席位**（原告席 / 旁听影壁 / 空阶），不是通道。东柱的 R04 虽然净高 2480，但它在 y 上只从 2000 到 3200 有地面，**上下都不通**——它是"一口井"，不是"一条路"。
- **节奏节拍**（5 拍）：

| 拍 | 房间 | 压力类型 | 预计时长 | 说明 |
| --- | --- | --- | --- | --- |
| ① 入庭 | R01 | 探索（尺度） | 50 s | 720×1280 的空门厅，没有敌人，只有"空" |
| ② 空庭 | R02 | 探索 + 环境 | 60 s | 判决石间歇落下，第一次看见名单把地面撑起来 |

| ④ 裁定 | R05 | 战斗（Boss） | 210 s | 两阶段：守印者档 90 s + 地形战 120 s |
| ⑤ 落判 | R06 | 叙事（选择） | 180 s | 无战斗、无计时、可暂停；两条落判都给可追责与异议机制 |

### 2.3 竖向设计

- **最大单房间落差**：1280（R01 的净高 1280、R05 的净高 1280）。**但全区没有任何一处"必须下落才能前进"**——所有下行段都是"走进去"，所有上行段都由石阶（≤170）或平台（320 档）承担。
- **最大净高**：R04 原告席 **2480**（v1.3 新增的高厅）。它不是落差，是"空腔高度"——它的地面在 3200（本区最低），顶部在 720（R08 的地面），中间 2480 全是空。**这个数字不许被当成落差使用**：R04 内部没有任何可上行的面，玩家全程站在 3200。
- **是否有贯穿全高的地标**：**没有竖直地标，这是刻意与 W24 相反的**。W24 用一条不断裂的垂直参照线（心湖穹顶）定位；W25 的定位物是**唯一的水平线**：R05 正北那道刻线（判决线，宽 1760、距地 200；过去态刻线是凹的、现在态刻线是凸的并被朱砂描过）。玩家在庭内任何位置都能看见它，且它的凹凸本身就在告诉你现在是哪个时代。
- **"空"如何落到数值**：R05 的可用战斗平面 1760×1280，中央 960×640 内**没有任何平台、柱、台**——这是全作最大的无障碍连续面。Boss 二阶段新增的三条沟槽是唯一的地形改造，且**不平移战斗平面**。

## 3. 探索技能应用点

本区玩家持有全部 8 项 + `VC@双刻`（W24 取得，主线必得）。**本区无能力门**（总控 §5：W25 能力门为空），下列九张卡只有 `VC` 是硬需求。

### 3.1 `VC` 时间切换（复用 · 主脉与 Boss 双必需）

- **应用房间**：R03（两态交替通行）、R06（台阶）、R05（Boss 二阶段被迫换时代）。
- **判定几何**：标准原子判定，角色碰撞 24×40。R03 中段过去态无落点（深 720）；R03 东段现在态塌梁高 400（不可跳、不可破）。
- **失败反馈**：切到 R03 中段的过去态会坠落并扣 1 血，落回西段地面，无提示文字（与 W01 第一次断桥同理：**让地形说话**）；切到东段现在态会被塌梁卡住 → 「当前位置无法使用该能力」（墙体重叠，原子拒绝，扣 0 血）。
- **是否门禁**：**是**（R03 两处、R06 一处）。
- **Boss 二阶段的特殊约定**：二阶段的换时代是 **Boss 强制**的（每 20.0 s），玩家不能拒绝，但**可以提前预判**（0.6 s 预告 + 铜齿鸣三声）。Boss 换时代时若玩家正处于"目标态会卡墙"的位置，Boss 的换时代**不做原子拒绝**（它不处理玩家位置）——改法是：Boss 换时代前 0.6 s 内，沟槽与卡墙点全部临时解算为安全（沟槽填平 0.4 s），**保证强制换时代永远不产生扣血**。这条写进 §8.5 伪代码。

### 3.2 `VC@双刻`（复用 · 只给信息）

- **应用房间**：R03（反向可读）、R05（二阶段判读）、R08（壁画合读）、R04（叠刻字）。
- **设计意图**：让玩家在"每 20 秒被强行换一次时代"的战斗里**不用切换也能看见另一套断面**——这是双刻在战斗中的唯一价值：**读**，不是躲。
- **判定几何**：无。纯渲染层（对比度 28%），不进入碰撞 / `_has_support` / 物理查询。
- **失败反馈**：无失败态。
- **是否门禁**：**信息门 3 处**（三处叠刻：R04 / R03 / R08）。这不是位移门——读对了只置旗标，不改变任何碰撞。

### 5.2 配置原则

- **威胁搭配**：R03 是全区唯一"三类型混编"房（远程 + 飞行 + 近战），因为它同时是机关房：抄录傀逼你离开字脊、墨蛾沿脊飞、缄口者把你往沟里拽。破解手段是**地形**不是伤害——站上 160 宽的宽字脊（x 1440—1600 段）可以让墨蛾撞脊自灭，缄口者拖不动站在宽脊上的玩家。
- **地形咬合（谁变强 / 谁变弱）**：
  - **变强**：缄口者在 R03 变强——现在态满地字沟，它只要把你拖进任意一条沟就白拿一血。过去态它几乎无害（白石无沟）。
  - **变弱**：抄录傀在 R02 变弱——空庭 720×1200 无遮挡，它的弹道一眼可读，可直接绕。
- **禁止走廊堆怪**：单房间敌人上限 **4 实体**（R03 是 4：抄录傀 2 + 墨蛾 1 + 缄口者 1，按组轮流启用，同屏不超过 4）；连续战斗房上限 3 间（R02→R03 = 2 间，R04 为支路，不构成连战）。
- **双时代影响**：E-02 名单墨蛾**只在现在态**（它沿字脊飞，过去态没有字脊）；E-01 抄录傀两态都在；E-03 缄口者两态都在但过去态弱化（拖拽位移从 60 降到 20，因为白石没有沟可拽）。

### 6.2 BOSS · 司历·删稿相（一场战斗，两阶段）

#### 叙事定位

它是**司历本人被删掉的那一稿**：负责删稿的官员，最终被自己的职务删成一个"相"。它守的印不是城门印，是**"哪个版本算数"的决定权**。它挡路的理由只有一句台词可说清：「你要公开的，是我删掉的；我删掉的，是我判过的。」它不否认事实，它主张"删稿也是一种裁定"。

#### 战场

| 项 | 值 |

#### 公平性条款（逐条对齐模板）

1. **所有攻击预警 ≥0.3 s**：实测最低 **0.6 s**（判词连击 / 强制换时代），P1 全部 ≥0.8 s。
2. **不得屏幕外起手**：Boss 只在镜头内起手；若玩家绕到其背后，Boss 先转向（0.3 s，**计入预警时间**）再起手，转向期间不产生判定。
3. **不得把玩家逼进必死角落**：
   - 三条沟**不是死亡判定**：落入沟中卡住 0.4 s + 扣 1 血，随后自动弹回最近字脊（弹回过程无敌 0.3 s）；
   - 四壁（东西南北）各留 240 宽的可站字脊带，任何角落都能侧移出；
   - 强制换时代前 0.4 s **临时填平沟槽**，保证"被时代换死"这件事不可能发生；
   - 席位塌落前 2.0 s 台面开始抖动（额外的第二重预告），且塌落不产生"把玩家压到沟里"的组合（塌落只发生在台面，不推人）。
4. **失败后有明确重试点**：死亡 → 回 R03 灯龛 (1600,2900)，Boss 满血重置，三门解锁 3 s 供玩家离开；已读叙事、已取道具、`w25_echo_sequence` 等进度全部保留；**不消耗任何资源**。
5. **Boss 前存档**：R03 灯龛是唯一灯龛，且 Player 必经（在 R03 的中段）。灯龛与 Boss 房之间只有一个房间的间隔（R03 北口 → R05 南口），死后 8 秒可回场。

- 本区是**度数为 2 的链尾**：西接 W24（主线进度门），东接 W29（暗区回看门）。W29 是终端（度数 1），不会再连长出去。
- 两个出口**都必须可原路返回**（总控 §5.3：`FINAL_DOOR` 战后仍可返回 W24；暗区门是双向的，不得做成单向陷阱）。
- 区内的"门"只有三处，全部为普通碰撞门（非进度门，非能力门）：R05 南门（常开）、R05 北门（Boss 战后开）、R05 西门（常开）。第四处 R04 东墙的秘门是**跨区门**，计入 N-2，不算区内门。

### 7.2 流程位置

- **在章节主线中的位置**：第 8 章第 3 区，也是**全作最后一区**；必经，且不可跳过。
- **首次到达路径**：W24 明日之门前庭东出 → R01 西阙门。
- **离开路径**：① 原路西出回 W24（`FINAL_DOOR` 永久双向）；② 落判后东出 R04 秘门去 W29（回看）。无其它出口。
- **落判（结局选择）在 R06 判后庭完成**，两条（总控 §4 第 8 章结局口径，本文件不改其内容，只给空间）：
  1. **公开原件 + 隐私延时**：原件全公开，七地代表私人信息延后 30 年解封；
  2. **公开原件 + 隐私托管**：原件全公开，私人信息交第三方托管，异议期 7 年。
  两者都要求"可追责与异议机制"，差异只体现在七地代表的政治成本与尾声旁白，**不做善恶二元**。选择后 `w25_verdict_sealed` 置位。
- **回访价值**：
  1. `w25_verdict_sealed` 后回 R04 / R03 / R08 读三处叠刻（若此前未读全）→ 进 W29 时 R01→R02 的门才会开（"结局 → 回看"的顺序，总控 §1.4 要求）；
  2. `w25_boss_down` 后上席台读第二道刻线（§3.11）；
  3. `ENDGAME` 已在 W24 置位，玩家可随时回第 1 章补支线。

### 7.3 连通性自查

- **全房间可达**：8 间从 R01 全部可达。R07 有三条入口（R01 蹬墙 / R06 西门 / R07 自身下行）；R08 从 R06 东门进；R04 从 R03 东门进。
- **不存在进入后无法离开的陷阱**：
  - R05 锁门只在战期；战败自动解锁 3 s 供离开；
  - R04 高厅（净高 2480）只有西侧一个入口和东墙一道跨区门，**内部无竖向通道**——玩家不会"上不去也下不来"，因为他全程只在地面 3200；
  - R07 竖井（净高 720）：可从 R06 西口进，也可从 R01 内壁蹬上；两端都通；
  - R03 的两态交替**不会产生死锁**：任一时态下玩家都能退回西段（无落点分支只会落回本房地面）；
  - 唯一的"扣血分支"（R03 中段切到过去态坠落）落回西段地面，不致死、不失能、不消耗资源。
- **跨区不构成循环**：W24 → W25 → W29 是链，W29 无其它出口，因此不存在"从 W29 绕回主线"的捷径。
