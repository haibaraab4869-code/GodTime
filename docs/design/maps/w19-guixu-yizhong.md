## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：一座**垂直收束的议事墓城**——归墟者的名字从下往上被审、被念、被删，最后钉在顶层的葬台上。它不是街道，是一座"从口到顶只有一条竖井"的判决塔。
- **视觉母题**：千名碑柱（一根贯穿全高 4000px 的名碑柱，柱面刻满姓名）、钟乳式的吊钟架（三层钟架各挂一面百口钹）、层间檐口（每层檐口挂一排骨牌，风过时成一片低频哗声）。
- **色彩基调**：过去 `#202849` 底 + 赭褐 `#BC8C64` 石面；现在 `#142032` 底 + 冷灰 `#657987`；强调色 **钟铜 `#A8712C`**（只在钟体、钹口与锁环上出现，是全图的唯一暖色，用来把"哪里会响"标出来）。
- **情绪曲线**：进入——从西侧低位门厅进来，抬头看不到顶（竖井把视线抽直）；中段——电梯上升时被迫看完整根千名碑柱（这是全作唯一一次"被强制看一个东西 12 秒"）；离开——葬台取 `DT`、破封壁、沿战后通路走出，钟声在背后收成一声。

### 1.2 关卡结构

- **主脉（14 房，含 4 间战场房）**：R13→R14→R12→R07→R03→R01（`DT`）→〔破地板〕→R05→R09→R10→R14→R16→R11（守印者）→R17→东出 W20。
  - 说明：R14 在链上出现两次不是错误，是"脊柱"的正常形态——电梯井把上下两层接在同一点，玩家不必绕行，但**必须在同一口井里上下两次**（一次上葬台、一次回主厅）。
- **支脉 A（上层，2 房）**：R01→R02→R04。`DT` 破壁后开；终点是葬台东龛（需 D2 音柱开门）。死路，同边返。
- **支脉 B（下层，2 房）**：R14→R16→R18（缄口执事战场）。精怪可选，战场门外可退。
- **暗环（1 条）**：R09→R12（竖井主段 ↔ 封存西廊）+ R07→R12（上厅 ↔ 封存西廊，过去态被无名灵封口）。给玩家一条"不坐电梯也能上下"的备路。
- **结构类型**：单竖井脊柱 + 三楼层 + 一条暗环（**不是网**：没有四向等分轴线，没有任何一层能横向贯通两个以上方向）。

### 1.3 与参考作的关系（合规声明）

| 借鉴的规律（编号见参考 README） | 本项目变体 | 与原型的差异点 |
| --- | --- | --- |
| 规律 2 · 一个世界只需要一个「网」（遗忘十字路） | 全作唯一的网是 W02 三角环；W19 是**脊柱**：一条竖井（R05→R09→R10→R14）串三层楼，每层只向两侧各开一扇门 | 参考的中枢是"四向等分网格 + 主环 + 死路侧袋"；本区**没有任何一层能横向贯通两个以上方向**，也没有主环——只有一个 8 字形的暗环（R09↔R12↔R07） |
| 规律 4 · 超大区必须有全高地标（泪水之城靠中央广场） | 地标是 **R09 千名碑柱**：一根贯穿 y=0—4000 的名碑柱，在电梯上行的 12 秒里始终在视野中，柱面姓名随层高变化（低层是刻痕深的老名，高层是被刮过的新名） | 参考的地标解决"我在哪"（空间坐标）；本区的地标解决"我在第几层被审"（**信息坐标**）——它不给方位，只给层级与进度 |
| 规律 6 · 过渡区要短 | 本区不承担"过渡"，它承担**多章回流**（北↑ W09 回环、东 W20、西 W17）与**身份审判**（守印者），因此房间全部服务于"上下" | 参考的泪水之城是 2.02:1 的**水平展开**城市街区（多层楼板 + 全高竖井 + 电梯井群，横 > 竖）；本区是 0.88:1 的**垂直收束**墓城（竖 > 横，只有一条竖井、三楼层、无街区层级、无电梯井群——只有一部电梯在三段井里跑） |

**地形相似度自查**：与泪水之城（2.02:1）**24/100**（拓扑 14 / 轮廓 2 / 母题 8），为全作最高分，仍低于 30 门限。失分点：① 横 vs 竖，断面朝向相反（2.02:1 → 0.88:1）；② 无街区层级、无电梯井群（只有一部单轿厢电梯）；③ 母题是"议事的墓城"（名碑、钹、檐口骨牌），参考是"雨中的城市"。
**明确禁止**：本区**不得**写成"泪水之城式的城市街区 + 多部电梯井群 + 横向连廊"。任何把某一层做成"可以横向走完 3 个以上房间"的改法，都会把中枢变成网，与总控 §1.3 的"全作只有一个网"直接冲突。

### 2.3 竖向设计

- **最大连续落差**：3200px（R01 地面 800 → R13/R15/R17 地面 4000），但玩家**永远不坠落**这条落差——所有上下都由电梯、檐口梯与蹬墙完成，这是"墓城"与"竖井"的分界：W12 天倾井考坠落，W19 考等电梯。
- **全高地标**：**R09 千名碑柱**——x=1320、宽 96 的一根柱，从 y=0 贯穿到 y=4000，柱面每 400 一段刻满姓名。玩家在电梯上行时，柱面在视野里从"刻痕深的老名"变成"被刮过的新名"（跨 6 段），走完即读完"归墟者从上往下被删"的顺序。
- **层间檐口**：每层檐口挂一排骨牌（每排 12 片），风过时成低频哗声；这排哗声是**听觉地标**——听到它就说明离檐口不到 400px。

## 3. 探索技能应用点

### 3.1 `DT` 龙尾破壁（**本区首次取得**）

- **取得点**：R01 龙尾葬台（过去态触碰龙尾骨，触发取得演出）。
- **取得前可进可出**：R01 与 R03、R07、R05 之间在取得前只有一条通路（R01 W→R03 上檐北廊 → 南落 R07），无任何单向门；取得过程中玩家不会被锁在房间里。
- **取得后立即自验证**（三件，按顺序）：
  1. **同纹理薄骨墙**：R01 东墙 → R02，一面与葬台壁完全同纹理的薄骨墙（骨纹细密 + 三道横划痕 + 蜡光）。破开 → 断尾壁龛。
  2. **同纹理地板**：R01 地板中央有一块颜色略浅的脆板（同三标签）→ 破开直落 R05 竖井上段（等价下行路线）。
  3. **不可破对照**：R01 西墙与穹顶是普通石面（只有骨纹、无划痕、无蜡光）——敲上去只有钝响，什么都不发生。这一条给玩家建立"三标签"的判据。
- **两态分别保存**：`w19_wall_broken_past` / `w19_wall_broken_present`；在过去态破的墙，切到现在仍然是完整的，必须再破一次。地板同规则（`w19_floor_broken`）。
- **每处破壁至少留一条原路**：R01 破壁后仍有 W→R03 的原路；R02 的唯一出口就是回 R01；R01 地板破开后，R03 的原路仍在。**没有任何一处破壁会把玩家关进死路。**
- **判定几何**：可破面必须是 96 的整数倍宽（R01 东墙 480×320、R01 地板 480×160、R16 东墙 480×320）；龙尾判定 `tail_width 32 / tail_height 48`，与 `combat_config.gd` 一致，本文件不重定义。
- **失败反馈**：非标记地形 → 钝响 + 无裂纹；标记地形 → 第一下裂一道竖纹、第二下裂三道、第三下破。
- **是否门禁**：是（R16→R17 是全作唯一"两态同封"的门，不开无法离开本章）。

### 5.2 配置原则

- **中枢不堆怪**：18 房只有 5 个战斗点，且全部不在竖井井道内（井道只有缄口者 2 组）。理由：中枢的职责是"回流"，井道被怪堵住会让每次回访都变成一次清怪。

- **破壁不关人**：R01 破地板后仍可从 R05 坐电梯上来；R02 死路可原路返。

### 8.4 状态与存档

| 旗标 | 含义 | 重置规则 |
| --- | --- | --- |
| `w19_checkpoint` | 灯龛（R07）已点亮（Boss 门前返回点） | 不重置 |
| `w19_lift_2` / `w19_echo_1` / `w19_tide_3` | 三机关正确档 | 不重置 |
| `w19_wall_broken_past` / `w19_wall_broken_present` | R01 东墙在**两个时代分别**被破 | 不重置（**分别存**，破一态不解锁另一态） |
| `w19_floor_broken` | R01 地板脆板已破（等价下行路） | 不重置 |
| `w19_seal_broken` | R16 东墙议冢封壁已破（两态同破，破一次即两态皆通） | 不重置 |
| `w19_sprite_calmed` | 无名灵已安抚 | 不重置 |
| `w19_elite_down` | 守碑骨将已杀 | 死亡后重置 |
| `w19_boss_down` | 百口墓钟已击败（同时是东出口的第二道条件） | 不重置 |
| `w19_rubble_cleared` | R11 北门落石已清（战后自动置位） | 不重置 |

- 死亡：回 R07 灯龛；Boss 战重置（阶段、血量、投影、落石恢复）；精怪重置；机关档位与破壁状态保留。
- **两种"破壁"语义不同，实现不得合并**：`w19_wall_broken_*` 是**两态分开**的（破一态只开一态的门），`w19_seal_broken` 是**两态同破**（封壁是一次性事件，破后两态都通）。这是总控 §5「`DT` 墙态两态分别保存，且每处破壁至少留一条原路」与 §4 第 6 章「破封壁后两态都能回行」两条规则的直接落点。

# 取得 DT（R01）
on_enter(R01):
    if has(DT): return
    if player_touch(tail_relic):
        grant(DT)
        show(self_test_hint = ["东墙", "地板", "西墙是普通石面"])   # 无文字，用材质高光

on_tail_hit(surface):
    tags = surface.tags
    if not tags.has_all(["bone_grain","three_scars","wax_gloss"]):
        sfx("dull"); return                       # 不可破非标记地形
    surface.hits += 1
    if surface.id == "R01_east_wall":
        if surface.hits >= 3:
            set_flag("w19_wall_broken_" + era)     # 两态分别存
            surface.destroy(era_only = true)       # 只在这一态塌
    elif surface.id == "R01_floor":
        if surface.hits >= 3:
            set_flag("w19_floor_broken"); surface.destroy(era_only = true)
    elif surface.id == "R16_east_seal":
        if surface.hits >= 3:
            set_flag("w19_seal_broken")            # 两态同破
            surface.destroy(era_only = false)

# 守印者
on_enter(R11) and not flag(w19_boss_down):
    lock_doors([R11.to_R16, R11.to_R17])           # 南门与北门（北门另有落石）

on_boss_hp_below(0.5):

    enable_three_floor_chorus(true)                # 三层依次发声，间隔 0.9s

on_boss_defeated(B-19):
    set_flag(w19_boss_down); set_flag(w19_rubble_cleared)
    unlock_all([R06, R08, R11, R17])
    clear_rubble(R11.to_R17)
    drop(章印)
