## 1. 地图主题与关卡结构

### 1.1 主题陈述
- **一句话主题**：这个区在讲什么（生活/制度/死亡/历法…），必须和章节叙事咬合。
- **视觉母题**：3 个可复用的形状/材质关键词（供美术与关卡共用），例如「悬索、铜钉、灰浆」。
- **色彩基调**：主色 / 辅色 / 强调色（十六进制），须与 [美术圣经](../art/art-bible.md) 不冲突。
- **情绪曲线**：进入 → 中段 → 离开，各一句。

### 1.2 关卡结构
- **主脉**：从入口到出口的必经路径，按「房间序号链」写出（如 R01→R03→R05→R07）。
- **支脉**：每条支脉的入口房间、终点奖励、是否回环。
- **结构类型**：线性 / 单环 / 多环 / 枝状 / 网状（选一并说明理由）。
- **节奏节拍**：把全区切成 3-5 个节拍，每个节拍标注「压力类型」（探索/战斗/机关/叙事/喘息）与预计时长（秒）。

### 1.3 与参考作的关系（合规声明，必填）
| 借鉴的规律（编号见参考 README） | 本项目变体 | 与原型的差异点 |
| --- | --- | --- |
| 如「规律 1 形状即玩法」 | 本区用 3.1:1 横条承载… | 差异：… |

> 硬性要求：本节至少 2 行。**地形相似度必须 <30%**：若本区与某个参考区域在「形状+入口数+主脉走向」三项上同时接近，必须改写其中至少两项，并在此说明。

## 6. 精灵、精怪与 BOSS

> 三档的区别必须严格执行（总控第 7 节六档表）：
> **精灵 = 活机关**（不可杀、单时代独占、靠切时代驱散或交互安抚，不锁门）；
> **精怪 = 可战斗精英**（有血条、有战场、锁门、不承担判决叙事）；
> **守印者 / BOSS = 门**（有台词、有立场、不击败不放行）。
> 把精灵写成可打的 Boss，会毁掉「打不过就绕」这条核心逃逸路线。

### 6.0 精灵（环境型生灵）

| 编号 | 名称 | 所在房间 | 单时代归属 | 阻挡方式 | 驱散/安抚条件 | 绕行代价 |
| --- | --- | --- | --- | --- | --- | --- |
| SPL-01 |  | R05 | 现在态 | 现在态封住主脉 | 切到过去，它会「不存在」 | 过去态路线更长/有水域 |

每只精灵必须写：
- **为何不可杀**：叙事上它是什么（三灵同源 / 未归档者 / 删稿残响），血条缺失要有世界观解释。
- **是否是通行条件**：它挡住的路是否为主线；若是主线，另一时代的路线必须真实可走（不能是假绕行）。
- **可读性**：玩家第一次遇到时，如何在 3 秒内明白「这不是敌人，这是机关」（形态、光照、音效、切时代时的反应）。

### 6.1 精怪（可战斗精英，锁门）

| 编号 | 名称 | 战场房间 | 战场尺寸 | 触发方式 | 阶段 | 招式与预警 | 破绽 | 奖励 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ELT-01 |  | R09 | 1024×384 | 进入即锁门 | 2 |  |  |  |

每只精怪必须写：
- **战场约束**：可用平台、可破坏地形、是否有环境危害（水/风/岩浆）、双时代是否改变战场形状。
- **招式表**：招式名 / 预警时间 / 判定窗口 / 伤害 / 可否格挡或闪避 / 冷却。
- **与守印者的差距**：招式数 ≤3、无阶段地形改造、无台词、削韧档 `elite`。写清它比守印者弱在哪一条。
- **失败与重试**：死亡后复位（门前返回点、战场重置、是否保留进度）。

### 6.2 守印者（章节 BOSS）
- **叙事定位**：他守的是什么印、为什么挡路。
- **战场**：房间、尺寸、地形要素（是否随阶段改造地形）。
- **阶段表**：阶段 / 血量阈值 / 新增招式 / 地形变化 / BGM 与镜头提示。
- **数值**：生命、削韧值、每招伤害、连续伤害保护间隔（默认 0.65s）。
- **公平性条款**：所有攻击预警 ≥ 0.3s；不可出现「屏幕外起手」；地形不得把玩家逼进必死角落。
- **战后**：奖励、能力/道具解锁、地图变化。

> 无 BOSS 的区写「无」，但必须写清「本区为何不需要 BOSS」（例如过渡区、秘境）。

## 9. 验收清单（AI 交付后逐条打勾）

- [ ] 所有房间矩形无重叠、相接边完全对齐
- [ ] 从主入口到出口存在可行路径（每段落差与跨度均在当前能力范围内）
- [ ] 每个能力门都有对应「取得点→首次使用→回访捷径」三段闭环
- [ ] 每区 ≥3 处双时代差异，≥1 处通行必需
- [ ] 所有道具坐标落在可行走区域内，且不被地形遮挡
- [ ] 战斗房敌人密度 ≤ 上限，连续战斗房 ≤ 3
- [ ] 精灵不可杀、单时代独占、绕行路线真实可走；精怪锁门且招式 ≤3
- [ ] BOSS/精怪所有招式预警 ≥0.3s，无屏幕外起手
- [ ] 若本区涉及 `VC@双刻`：只给信息，未写成位移能力（不可踩虚影平台）
- [ ] 出口均有回程路，不存在单向陷阱
- [ ] `data/wXX.json` 可被解析，字段与本文档一致
- [ ] 地形与参考作的相似度自查 <30%（附对照结论）

## 术语表（全 25 张图统一，禁止自创同义词）

| 术语 | 含义 |
| --- | --- |
| 房间 | 一次镜头容纳的空间单元，有独立矩形与地面高度 |
| 分区 | 3-6 个房间组成的功能段落（入口段/主厅/战斗段/秘室…） |
| 主脉 | 从入口到出口的必经房间链 |
| 支脉 | 从主脉分叉、尽头有奖励的死路或回环 |
| 能力门 | 不满足条件无法通过的地形/机关，必须绑定一个探索技能 |
| 精怪 | 有专属战场与独立机制的精英敌人，非 BOSS |
| 守印者 | 章节 BOSS，四阶段以内，削韧可破 |
| 双时代差异 | 同一房间在过去/现在两态下的地形或通行差异 |
| 灯龛 | 存档与恢复点 |
| 回访捷径 | 获得新能力后从本区打通、连接回已探索区域的通路 |
