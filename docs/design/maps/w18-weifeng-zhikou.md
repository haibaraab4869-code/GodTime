## 1. 地图主题与关卡结构

### 1.1 主题陈述

- **一句话主题**：这里是"未归档者"的藏身处——**没被索引的人不进 UI**。所以本区没有 HUD、没有文字、没有地图标注，连血条都被换成角色身上的三段微光。割裂不是美术风格，是世界观直译。
- **视觉母题**：灰阶骨砖（去色相的等高砖缝）、倒扣船肋（弧形肋条成洞口）、蜡封（半透明米白，只在破壁时裂开成三道竖纹）。
- **色彩基调**：全图去色相，仅两档明度——暗 `#3A3A38` / 亮 `#9A9890`；唯一暖色是**过去态光柱与现在态灼痕** `#C8A46A`（同一形状、不同时代：过去是光，现在是烫痕）。这是"无光源时代靠过去光路反推"的视觉基础。
- **情绪曲线**：进入——南口下沉、光与声同时被抽走（HUD 消失的瞬间是第一记）；中段——病房残排的静默与"人还在"的错位；离开——破壁后听到蜡裂的三声，回到 W17 才恢复 HUD（听觉先回来、信息后回来）。

### 1.2 关卡结构

- **主脉（6 房）**：R01→R03→R05→R06→R07→R08。**两段强制换时代**：R01–R03 为现在态（折梯完好），R06 井口为过去态（现在态涨水封到 32px < 角色 40）。
- **支脉（2 房）**：R01→R02→R04（过去态浮栅落下才通），终点是病房残排（凶骨 + 两态合读的姓名木牌）。**死路，同边返回**。
- **结构类型**：单主线 + 一条下层分叉（枝状），无环。理由：秘境必须"单主线"（总控 §1.3 准入秘境定义），任何环都会让"未索引"的封闭感失效。
- **节奏节拍**：

| --- | --- | --- | --- |
| 1 | R01 | 探索（HUD 消失、无文字） | 30 s |
| 2 | R03 | 通行（折梯井上行，第一次"只有现在能上"） | 45 s |
| 3 | R05 | 通行 + 收藏（船骸洞 → 麒麟材料） | 50 s |
| 4 | R06 | 机关（石镜光路，过去校准 / 现在反推） | 90 s |

| 支 | R02–R04 | 战斗 / 叙事（凶骨、病房木牌） | 60 s |

### 1.3 与参考作的关系（合规声明）

| 借鉴的规律（编号见参考 README） | 本项目变体 | 与原型的差异点 |
| --- | --- | --- |
| 规律 8 · 风格割裂是被允许的（蜂巢 2.33:1，钥匙准入） | 本区 1.05:1 近正方，割裂的手段不是换色板而是**撤 UI**：HUD、伤害数字、地图标注、所有文字全部消失，只留三段微光当血条 | 参考的蜂巢靠"暖黄 vs 冷蓝"的色相对立 + 钥匙资格；本区**去色相**（灰阶），资格不是钥匙而是"你愿不愿意不带地图走"；割裂的理由是叙事状态（未归档 = 不可被索引），不是地理封闭 |

## 3. 探索技能应用点

### 3.1 `VC` 时间切换（每区必用，复用）

- **应用房间**：R02（浮栅）、R03（折梯）、R05（船骸）、R06（光路 + 井口）。
- **设计意图**：本区是本章唯一"每走两房就要换一次时代"的区域——把 `VC` 从"解题工具"变成"走路方式"。
- **判定几何**：浮栅 800 高 × 1120 宽（整面）；井口净空 32px；浮床 480 净宽归零。
- **失败反馈**：在栅/床/井口切时 → 「当前位置无法使用该能力」，0 伤害、无冷却；因为无 HUD，这条提示是本区**唯一允许出现的文字**（系统级提示不受"无文字"约束，否则玩家无法理解拒绝）。这条必须写死进实现，否则秘境会变成"不知道为什么过不去"。
- **是否门禁**：是（R02、R03、R06 井口）。

### 3.2 `DT` 龙尾破壁（本章末在 W19 取得，本区为**回访用途**）

- **应用房间**：R07 北墙（同纹理蜡封脆壁）。
- **设计意图**：给 `DT` 第一个"跨区用处"，让玩家理解破壁不是只能用于主线封壁。
- **判定几何**：脆壁 480×320，纹理特征 = 骨纹细密 + 三道横划痕 + 蜡面反光；**只认这三条标签**，不认"看起来像墙"。
- **失败反馈**：非标记地形无反应（龙尾敲上去只有钝响）；标记地形敲两下裂三道竖纹、第三下破。
- **是否门禁**：是（R08 深层只能破壁进；本次首访不取，回访取信）。

### 3.3 `DB` 龙息冻水（第 7 章，未来回访钩子）

- **应用房间**：R02（现在态 208 深水）。
- **设计意图**：给一个"以后能抄近路"的钩子，不改变本次流程。
- **判定几何**：水面 208 深 → 冻结后形成 2 块踏台（`ice_max_platforms` 上限内），可从 R01 直接走上 R04，跳过浮栅。
- **是否门禁**：否。

### 3.4 `PW` 蹬墙（备用，非必需）

- R03 折梯井侧壁有可蹬材质（`bone_pillar`），过去态封板下方仍可蹬——允许玩家用 `PW` 硬上 R05，**这是给"忘记换时代"的玩家的兜底**（不是设计正解，正解是现在态走折梯）。兜底存在的原因：无 HUD 区里迷路成本太高，需要一条不依赖读提示的出路。

### 5.2 配置原则

- **总量克制**：秘境 2—3 组（本区 3 组 / 6 只实体）。这是一个"几乎不打架"的区域，敌人存在的目的是让静默有重量，不是提供节奏。
- **无预警音的设计**：静默巡房与缄口鸦都**不发攻击音**（世界观：缄口 = 无声）。预警改由**视觉**承担：巡房的影子比本体早 0.4s 移动；缄口鸦起飞时会抖落一片灰。这条必须在实现里写死——无声音 + 无 HUD 的组合若再没有视觉预警，会变成不公平伤害。
- **地形咬合**：现在态的涨水让 R02 的浮栅成为"击杀不了的水墙"，玩家在栅前被涨水涌推回时才会想到换时代；过去态水退，涌消失，但静默巡房占住桥面。
- **密度上限**：单房 ≤3；连续战斗房 ≤1（R02、R04 之间隔一个折梯井）。
- **与精灵/精怪的关系**：本区 0 精灵 0 精怪——秘境不设锁门战场（一旦锁门，"未索引"的开放感立刻消失），压力全部由环境与静默承担。

## 6. 精灵、精怪与 BOSS

### 6.0 精灵

**无。** 第 6 章的两只精灵分别落在 W17（骨牌灵）与 W19（无名灵），本章已满配 2 只；本区若再放精灵，会把"三灵同源"的稀缺性稀释。本区的"活机关"功能由**浮栅 + 涨水涌**承担——它们同样是"切时代即改变行为的环境体"，只是没有生灵形态。

### 6.1 精怪

**无。** 精怪的定义是"有专属战场并锁门"，而秘境的核心是"不锁门的开放小体量"；本章两场精怪已在 W17（缄口听差）与 W19（缄口执事）。本区不设精怪的理由不是体量不够，而是**锁门会破坏"未索引"的语义**：一个不能被系统索引的地方，不该有一扇系统锁上的门。

### 6.2 守印者 / BOSS

**无。** 秘境不承担章末把关（总控 §1.3：秘境单主线、回报放在出口）；第 6 章守印者「百口墓钟」在 W19。本区若设 Boss，`DT` 就变成"打赢才能拿"，与总控 §5「`DT` 取得点在 W19 龙尾葬台，取得前可进可出」冲突。

### 8.4 状态与存档

| 旗标 | 含义 | 重置规则 |
| --- | --- | --- |
| `w18_checkpoint` | 灯龛（R01，无菜单，触碰即存档） | 不重置 |
| `w18_mirror_2` | 光路已命中（门永久开） | 不重置 |
| `w18_wax_past` / `w18_wax_present` | 蜡封脆壁在**两个时代分别**被破 | 不重置（两态分开存，破一态不解锁另一态） |
| `w18_letter_taken` / `w18_relic_taken` / `w18_page_taken` | 信 / 麒麟材料 / 地图残页已取 | 不重置 |

- 死亡：回 R01 灯龛；敌人重生；机关档位保留。
- 蜡壁两态分开存的理由：`DT` 的规则是"墙态永久保存且两态分别记录"（总控 §4 第 6 章），本区是第一个这样实现的地方——在过去破开、切到现在，墙**仍然是完整的**，必须再破一次。这不是 bug，是本区最重要的教学点。

### 8.5 伪代码

```text
# 浮栅（R02）
on_era_changed():
    gate.pos = (era == PRESENT) ? 0 : 800          # 现在升起 800，过去落下
    bed_block = (era == PRESENT)                   # 空床被水浮起挡门

on_switch_era():
    if body_overlaps(gate_target_rect) or body_overlaps(bed_target_rect):
        refuse("当前位置无法使用该能力"); return

# 井口（R06→R07）
can_enter(R07):
    if era == PRESENT: clearance = 32              # 水面到檐下
    else: clearance = 800
    return clearance >= 40

# 蜡封（R07 北墙）
on_tail_hit(wall):
    if not wall.tags.has_all(["bone_grain","three_scars","wax_gloss"]):
        return NO_EFFECT                          # 不可破非标记地形
    hits += 1
    if hits >= 3:
        set_flag("w18_wax_" + era)                # 两态分别存
        wall.destroy(era_only = true)

# 光路（R06）
on_mirror_rotate(level):
    if era != PAST: return NO_EFFECT              # 现在无光源
    if ray_cast(mirror, level) hits receiver:
        set_flag("w18_mirror_2"); open_door()
```
