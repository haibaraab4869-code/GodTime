怎么用这批参考

两张图层配合看：全图回答「区域之间怎么连」，区域拆解图回答「一个区域内部怎么长」。前者决定世界图，后者决定房间。

  • 先看比例：每个区域的宽高比直接决定它是走廊、盆地还是竖井，卡片右上角都标了。
  • 再看开口：数一数每个区域有几个出入口，进出方向决定它在世界图里是枢纽、动脉还是死胡同。
  • 最后看密度：战斗区、叙事区、迷宫区在图上明显不是同一种笔触。
