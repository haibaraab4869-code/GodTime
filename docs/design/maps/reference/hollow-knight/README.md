## 这批图能回答什么

## 从这批图里提炼的通用规律

写进下一版地图规格前，这八条是最值得先定下来的：

1. **形状即玩法**：上面的比例不是巧合。4.8:1 的水道只能是动脉，0.97:1 的边境只能是攀爬。每设计一个区域，先定宽高比，再定房间。
2. **一个世界只需要一个「网」**：只有十字路是真正的多向网，其余区域都是「一根主脉 + 支脉」。全部做成网状等于全部没有结构。
3. **一个世界只需要一条「动脉」**：水道把东西两端拉通；再多的横贯区域会让世界失去纵深。
4. **超大区必须有全高地标**：泪水之城靠中央广场当坐标系。没有地标的 25000px 区域就是迷宫。
5. **教学交给地形**：国王山道没有一句提示，全靠落差与门洞形状。这条直接适用于本作第一章。
6. **过渡区要短**：雾之峡谷的价值是「缝合」，不是「表现」。玩家的耐心预算优先给枢纽和秘境。
7. **迷宫靠撤信息，不靠加难度**：深巢不给地图。恐惧来自失去方向；回报必须放在出口。
8. **风格割裂是被允许的**：蜂巢整体暖黄，和全世界的冷蓝对立。一个需要资格才能进的区域，可以完全跳出色板。

## 与本项目的对接方式

- 本作是**八章 48 区**结构，比空洞骑士的十来个区域更碎。上表的「角色」列（中枢 / 动脉 / 过渡 / 秘境 / 边界 / 终局）可直接作为 48 区的**类型配额**参考：中枢与动脉要少，过渡要更碎更短。
- 第一章的开场长廊、首个枢纽、首条过渡，建议直接对照 King's Pass → Forgotten Crossroads → Fog Canyon 这条链。
- 本作的核心差异是**时间切换（过去 / 现在）**：参考图只有单一时间层，读图时应额外问一句「这个区域切到过去会变成什么形状」——这是本项目独有的设计增量，图上没有答案。

## 重新生成预览

若替换或新增 `regions/` 下的原图，可用下面的脚本重建预览与缩略图（在仓库根目录执行）：

```bash
python - <<'PY'
from PIL import Image
Image.MAX_IMAGE_PIXELS = None
import glob, os
os.chdir("docs/design/maps/reference/hollow-knight")
for f in sorted(glob.glob("regions/*.png")):
    base = os.path.basename(f)[:-4]
    im = Image.open(f).convert("RGB")
    big = im.copy(); big.thumbnail((2400, 2400), Image.LANCZOS)
    big.save(f"previews/{base}.jpg", quality=86, optimize=True, progressive=True)
    small = im.copy(); small.thumbnail((620, 620), Image.LANCZOS)
    small.save(f"thumbs/{base}.jpg", quality=82, optimize=True)
    print(base, im.size)
PY
```

> 新增区域后需同步在 `index.html` 的 `REGIONS` 数组中加一条（含中英文名、标题像素尺寸、角色、结构观察、可借鉴点），否则卡片不会出现。
