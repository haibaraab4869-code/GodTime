# 三灵实体机关实现 v5

2026-10-27，按48区设计（原「三灵地图重构要求」文档已于 2026-10-30 随地图文档清空）将原答题式机关替换为现场环境机制。M01—M48均实例化独立机关室配置，扩展净高至384并重新布置完成点；保留48区、488个房间节点和62条区域连接。

## 实际玩法

- 水路改道：分流阀改变水域范围与横流，正确支渠灌注完整机关室；水面逐渐升降，必须游至高处接收点，S可潜至水下侧门。
- 潮位蓄泄：水尺控制80／144／208三种水深，水面不是实体墙。角色随水面浮起，可泳跳与下潜，正确水位才激活完成点。
- 风场穿行：旋转导流翼使风核对准真纹。正确风向提供上升气流与逐图区别的横风，错误风向下压；借风抵达上层阳台。
- 根系生长：保留正确活根后生成可碰撞阶桥，角色沿根桥跃往高处；完成因果后，根桥不因重选档位消失。
- 机关重构：校准齿轮相位后，AnimatableBody2D平台沿逐图行程与速度升降并承载角色，可跳往高处接收台。机关室内冲突的旧踏板已移除。
- 光影辨伪：旋转石镜使光路向上／向右／向下折射，物理射线检测能否命中接收器，遮挡物会阻断光路。正确档位与实际命中必须同时成立。
- 回声记忆：过去播放龙／凤／麟三种音色并提供可阅读顺序；未来在三根实体音柱上重复3—5音的逐图序列。错音仅重置当前序列，过去站1可重播。
- 三灵协作：分别校准水轮、风轮和地脉。水轮提供浮力，风轮在按住跳跃时提供上升气流，地脉生成根桥；三项校准并抵达高处后锁定因果。

## 输入、保存与兼容

Tab仍切换过去／未来，目标碰撞冲突时原子拒绝；E只操作现场装置、神兽站或NPC，不弹三选一答案窗。边缘自动过图继续使用冷却与离区重武装。S／方向下／手柄左摇杆向下是可重映射的水中下潜。

每区device档位与echo结果保存在chapter_flags，独立于永久能力和剧情。旧存档已完成机关保留进度，缺失装置字段时使用已解的目标相位。灯龛提供“重试本图三灵机关”，仅复位本区，不清除剧情、能力、战斗奖励与其他地图。

## 实现与验收范围

`game/mythic_environment.gd`实现动态机制，`mythic_puzzle.gd`管理跨时代进度，`world_data.gd`生成机关碰撞快照，`world_game.gd`接入交互与移动。48区配置当前已固化在 `game/data/world_regions.json` 中；原负责生成该配置的 `tools/build_mythic_design.py` 与 `tools/build_world.py` 已于 2026-10-30 随地图文档重建一并删除，配置的后续维护方式待新地图方案确定。验证见[RUN-0010](../qa/runs/RUN-0010-mythic-environment.md)。`tools/capture_mythic.gd`在不读写用户进度的实例中渲染八类机关。

本轮是可运行机关与碰撞灰盒。宏观房间网络沿用上一版，最终美术、完整叙事演出与逐房间人工节奏验收尚未完成。水采用二维区域浮力，不是流体体积模拟；齿轮视觉驱动升降台，不模拟逐齿接触。旧九份地图DOCX仍为上一版快照，本轮以设计MD、运行规格和代码数据为准。
