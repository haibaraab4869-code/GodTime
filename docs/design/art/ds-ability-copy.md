## 3. ② 战场提示碑（W16 R09 灯龛旁）

### 3.1 现状载体（已核实，非凭空想象）

- 运行时 `game/data/world_regions.json` 的 W16 `interactions` 共 **15 条**，其中**没有任何「提示碑 / 告示 / 碑 / sign」类交互**（已脚本核对为空）。
- R09（正殿前厅，rect `(640,416,320,416)`，floor_y `832`，era `both`）内现有交互三处：
  - `rest`（灯龛 · 正殿前厅）@ `(800,792)`
  - `item_I06`（魂魄沉淀点）@ `(760,792)`
  - `device_0`（三灵协作 · D1 水轮主站）@ `(800,812)`
- 结论：**「战场提示碑」是尚不存在的新资产位**，不是「给已有对象补文案」。

### 3.2 文案（两行，碑文不可拆读，一次调查一并显示）

- 第一行（规范句，逐字，复用 `ABILITY_USAGE["DS"]`）：
  > `龙鳞只挡地形的热，不挡敌人打你。`
- 第二行（本区专属战术提示，24 字 ≤ 30，世界内说法、不解释机制；沿用 w16 §6.2 公平性条款 4 已定句）：
  > `借火的殿里只有盐台是凉的——没有鳞也能靠盐台打完`

### 3.3 视觉规格

| 项 | 值 |
| --- | --- |
| 形态 | 立碑（竖长盐晶/骨石板，地面锚定） |

| 刻字色 | 焦墨 `#13110F`（对赭白底对比度 ≫ 3:1，过去/现在两态皆可读） |
| 鳞光点缀 | 碑额一撇鳞光 `#E0A040`（与「鳞光 = DS 能力唯一视觉标识」一致，仅小点缀，不构成护甲光环） |
| 时代 | `both`（R09 前厅无时代差异，两态皆在） |
| 交互半径 | 60（与既有叙事物 item 一致） |
| 字体 | 沿用引擎默认 Label 字体（当前无定制字体资产）；世界内刻字 15，碑名可 13 |

### 3.4 摆放位置建议（区局部画布坐标）

- **建议坐标：`(868, 792)`**
- 依据（四边余量全部 ≫ 20px，且不压任何既有交互点）：
  1. 落在 R09 rect 内：左 228 / 右 92 / 上 376 / 下 40。
  2. 紧邻灯龛（800,792），水平距 **68px**，读作「灯龛旁」；与灯龛图元（`rest` 画在 x 790—810）不重叠。
  3. 与魂魄 I-06（760,792）相距 **108px**、与 device_0（800,812）相距约 **71px**，均不抢同一交互半径。
  4. 与东墙（x=960，R09→R10 门）留 **92px**，不堵门、不贴墙。
  5. 与灯龛同高（y=792 = floor_y 832 − 40），站在地面即可读，无需跳跃。
- 备选：如需更靠墙可右移至 `(884, 792)`（再右 16px）；**不建议**放灯龛左侧（与 I-06 仅 40px，过挤）。

### 3.5 实现建议（交工程侧，本文不改代码）

推荐**数据驱动 + 复用「井壁刻字」先例**，最小改动如下：

1. **数据**：`docs/design/maps/data/w16.json` `items[]` 追加一条；`_schema.md` §Item 的 `type` 白名单（第 75 行）新增 `提示碑`：

2. **转换器**：`tools/build_runtime_world.py` item 分支（第 373—391 行）对 `type == "提示碑"` 生成 `id = "sign_" + raw["id"].replace("-","")`（例 `sign_I09`），带 `kind: "提示碑"`、`radius: 60`、`room`、`at`；**不要**并入一次性收集语义（不要走「已收录、不再重复出现」）。
3. **引擎**：`game/world_game.gd`
   - 新增常量 `const DS_BATTLE_HINT := "借火的殿里只有盐台是凉的——没有鳞也能靠盐台打完"`。
   - `_interact`（第 473 行起）在 `item_` 分支**之前**加：`if id.begins_with("sign_"):` → `_show_entry("战场提示碑", ABILITY_USAGE["DS"] + "\n" + DS_BATTLE_HINT)`；**可反复读、不置旗标、不扣资源**。
   - `_draw`（第 661 行起）在 `view_inscription` 分支附近加 `sign_` 分支：画竖长碑体 `draw_rect` + 碑额鳞光小 `draw_arc`，样式对齐 §3.3。
- **备选（最小改动，非数据驱动）**：直接在 `_interact` 加固定 id `"battle_sign_ds"` 分支 + `_draw` 为 W16 特判。**不推荐**（把位置与文案写死在代码，违背 29 区数据驱动原则，且红线句应复用常量而非再抄一遍）。

## 4. ③ HUD 状态图标说明

### 4.1 现状载体（已核实）

- `game/world.gd` `_build_ui`（第 110—161 行）：HUD 是单个 `Label`（`hud`）+ 顶栏 `ColorRect`（高 116），**无任何图标节点、无 tooltip 节点**。
- `game/world_game.gd` `_update_hud`（第 348—352 行）：只拼一段文字（章节/区名/时代/生命/药/魂魄/凶骨 + 战斗），**不含能力图标、不含 per-ability 说明**。
- 说明文字当前唯一来源是 `ABILITY_USAGE`，只在取得面板「神权重现」条目出现一次，**没有「持有状态下的常驻说明」**。

### 4.2 文案

- 仅红线句（逐字，复用 `ABILITY_USAGE["DS"]`）：
  > `龙鳞只挡地形的热，不挡敌人打你。`
- **不加**辅助句：§3.1 红线只对「能力描述 / 提示碑 / HUD 状态」三处逐字一致；HUD 说明不含战术提示。

### 4.3 视觉规格

| 项 | 值 |
| --- | --- |
| 图标形态 | 龙鳞片小图标 |
| 尺寸 | 20 × 20 世界像素（顶栏内徽标） |
| 图标色 | 鳞光 `#E0A040`（W16 §1.1「鳞光 = 能力唯一视觉标识」），外轮廓焦墨 `#1C1A17` |
| 说明文本 | 红线句，字号 14—15，纸白 `#F8F0E3`，置于深色 tooltip 底（复用顶栏 `Color(0.055,0.09,0.11,0.94)` 作底） |
| 出现时机 | 持有 `DS`（`ability_available("DS") == true`）即常驻显示图标；未持有不显示 |
| 位置 | 顶栏 `hud` 文本行右侧（避开 objective 自动换行区） |

### 4.4 实现建议：小图标 + tooltip（非纯文本）

- **图标**：推荐**程序化矢量**（一个 `Control._draw` 画一枚鳞片：两条弧线 + 高光点，色 `#E0A040`），与 `_draw` 既有图标族一致、零新资产、无导入负担；备选一张 `ui/` PNG（`ui_ds_status.png`，20×20，近邻过滤）。
- **说明**：图标 hover（鼠标）/ 聚焦（手柄）时显示 tooltip，文本 = 红线句。
- **无障碍（本规格强制）**：tooltip 不得「仅 hover 可达」——
  - 手柄：图标可聚焦（纳入现有焦点/日志体系，或长按调查键显示）。
  - 提供「状态说明常驻」开关（`settings_panel.gd`），开启后红线句常驻顶栏第二行，满足无 hover 玩家与低视力。
  - 对比度：`#E0A040` 对顶栏深底 ≫ 3:1；红线句纸白 `#F8F0E3` 对深底 ≫ 4.5:1。
  - 图标带形状轮廓（不只靠颜色区分 DS 状态），可加 0.5px 亮边。
- **接入点**：`_update_hud`（或新增 `_update_status_icons` 由 `_update_hud` 调用）判断 `ability_available("DS")` 控制图标显隐；`ability_available` 定义在 `world_game.gd` 第 222—223 行。

## 7. 发现但未改的问题（交工程侧 / 主理人）

1. **W16 R09 灯龛旁没有「提示碑」对象**——需**新建**交互 + 图元 + 转换器/引擎分支（见 §3.5），本质是「新建资产位」而非「补文案」。
2. **HUD 无任何能力/状态图标体系**——DS 图标将是本作第一枚状态图标；建议顺带立一个最小「状态图标位」约定（未来 QS 血格、DB 冰面等可复用），避免每能力各写一套。
3. **红线句句末「。」口径**：`world_game.gd` 第 12 行已落地规范串**带句号**（`…打你。`），而 `ability-grants.md` §3.7 与 `w16` §3.1 / §6.2 正文写法**不带句号**（`…打你`）。本文以已落地面板常量（带「。」）为唯一真源；文档侧若要统一需主理人拍板，但**不得**因此改动 `ABILITY_USAGE["DS"]` 或破坏三处逐字一致。
4. **`device_0` 运行时坐标与 w16 文档正文不一致**：运行时水轮主站在 `(800,812)`（转换器按房中心 × floor−20 归一），文档 §2.2 写「水轮 (700,700)」。本文碑位（868,792）已避让运行时坐标，不碰 device_0；该漂移属既有数据 vs 正文问题，不在本任务范围内改。
5. **目录并存提示**：既有美术圣经/资产清单在 `docs/art/`，本任务指定输出 `docs/design/art/`。若希望美术文档归口 `docs/art/`，可整体移动本文件，内容不受影响。
