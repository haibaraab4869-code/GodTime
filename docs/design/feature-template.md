## 4. 边缘情况与滥用防护

至少覆盖并逐项写明“触发条件｜预期行为｜界面反馈｜测试点”：

1. 边界值：零值、最大值、资源不足、时间/范围临界点。
2. 状态中断：暂停、死亡、切场景、读档、重复触发/快速连按。
3. 系统冲突：多个效果叠加、与其他功能同时生效、输入冲突；不适用须说明。
4. 其他与本功能相关的软锁、刷取或进度绕过风险：待填。

- [ ] Given 待填 / When 待填 / Then 待填（正常路径）
- [ ] Given 待填 / When 待填 / Then 待填（资源不足或失败）
- [ ] Given 待填 / When 待填 / Then 待填（边界或状态中断）
- [ ] 逐项完成立项案对照：每项设计有核对的章节/页码和对照结论；原案未明确、补充或冲突项已登记且未冒充获批。
- [ ] 如存在原案未明确、补充或冲突等偏差，已记录原案依据、原因、跨专业影响、候选方案，并附用户书面批准证据（链接或记录位置、审批人、日期和明确结论）；未获批的偏差不得定稿、排期、实现，也不得据此通过验收。
