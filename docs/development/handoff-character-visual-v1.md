## 3. 缺陷实测（2026-10-29，深蓝天空 `#142032`）

| 对象 | 主色 | 对天空对比度 | 判定 |
| --- | --- | --- | --- |
| **rig 合成图** `char_shihung_rest_composite.png` | `rgb(16,16,8)` | **1.17** | ✗ 低于 3.0 |
| `gen_parts.py` `INK`（袍身） | `rgb(34,31,28)` | **1.00** | ✗ 完全糊死 |
| `INK_SLEEVE` | `rgb(48,44,39)` | 1.18 | ✗ |
| `INK_BACK` | `rgb(28,26,23)` | 1.06 | ✗ |
| `INK_FAR` | `rgb(24,22,19)` | 1.10 | ✗ |
| `HAIR` | `rgb(19,17,15)` | 1.15 | ✗ |
| **AI 母版** `master_128.png` | `rgb(124,122,115)` ≈ `#7B7A74` | **3.81** | ✓ |
| AI 母版最暗层（描边/头发） | `rgb(50,48,48)` | 1.25 | ✓ 允许——母版就是靠它糊进天空 |
| 金饰 `GOLD` | `rgb(198,158,44)` | 6.49 | ✓（当前渲染里唯一能读的元素） |

**注意母版的明度结构只有两个极端**：袍身 3.81、描边/头发 1.25，中间几乎没有别的层。它没有用"梯子式"的多个中间灰——这是它看起来干净的原因，也是 T1 表要模仿的形状。

**结论**：这正是 art-bible §2.6 里写死的阻塞缺陷，在 rig 上**第二次复现**（第一次是母版压暗，已记在 spec §11.3）。当前主角在深蓝天空里只剩金冠和金线可辨，袍身是一整块黑。

## 4. 任务

### T1 · 换墨色阶（必做）

改 `tools/gen_parts.py` L28–L41 的常量（L27 是 `# 墨色阶` 注释行），然后重跑该脚本生成 16 部件与 preview。

**改法原则**：从「五种深度不同的黑」改成「亮袍 + 深线 + 金饰」。主体（袍身、袖、后片、远侧肢体）必须过 3:1；描边与头发**允许糊进天空**——那反而让边缘更干净，与母版一致。

**这些值不是估的，是按定稿母版 `master_128.png` 实测反推的**（`tools/sample_master_ink.py` 采样母版明度分布，`tools/ink_ladder.py` 反解并校验下面整张表，末段输出「总判定」）：

母版的明度结构实测如下——它**没有纯黑**，最暗处就是描边和头发，且对天空只有 1.25:1：

| 母版层 | 实测色 | 对天空 CR | 对袍身 CR |
| --- | --- | --- | --- |
| 最暗 5%（描边 + 头发） | `(50,48,48)` | **1.25** | **3.05** |
| P25（分布参考，非设计目标） | ≈ `94` 灰 | 2.42 | 1.53 |
| **P50 袍身** | `(124,122,115)` | **3.81** | 1.00 |

所以「描边糊进天空」不是妥协，是母版的本来形状：**描边对袍身 3.05:1、对天空 1.25:1**，边缘靠袍身与天空的落差定义，而不是靠一圈亮线。

| 常量 | 现值 | **改为** | 对天空 CR（现→新） | 说明 |
| --- | --- | --- | --- | --- |
| `INK_FAR` 远侧肢体 | `(24,22,19)` | **`(88,87,82)`** | 1.10 → **2.26** | 被躯干遮挡层，可低于 3 |
| `INK_BACK` 后片裙摆 | `(28,26,23)` | **`(102,101,96)`** | 1.06 → **2.80** | 同上 |
| `INK` 袍身 | `(34,31,28)` | **`(123,122,116)`** | 1.00 → **3.80** | 锚点，照抄母版 P50 |
| `INK_SLEEVE` 近侧袖 | `(48,44,39)` | **`(138,137,130)`** | 1.18 → **4.66** | 必须比袍身亮一档（原有设计意图，理由见代码注释 L31） |
| `HAIR` 头发 | `(19,17,15)` | **`(50,48,46)`** | 1.15 → 1.18 | 与描边同档 = 母版最暗层，靠金冠与肤色分离 |
| `INK_EDGE` 描边 | `(13,12,10)` | **`(50,48,48)`** | 1.19 → **1.25** | 照抄母版最暗实测值，对袍身 3.05:1 |
| `CREASE` 褶皱 | `(8,7,6)` | **`(84,82,78)`** | 1.23 → **2.10** | 袍身内部的线，必须**比描边亮**，对袍身 1.81:1 |
| `GOLD` / `GOLD_D` / `SKIN` / `SKIN_FAR` / `PAPER` | 不改 | — | — | 金饰 6.49、肤色 14.40，已经很稳 |

> **务必注意 `INK_EDGE` 与 `CREASE` 的次序**：旧墨阶里 `CREASE(8)` 比 `INK_EDGE(13)` **深**，因为那是纸白底上几乎同色的两条淡线，谁深谁浅看不出来。换到深蓝底、袍身提亮后，若沿用「褶皱比描边深」的旧关系，褶皱会变成比外轮廓更重的死黑线，读成脏点。**新关系是 `CREASE(84)` 明显浅于 `INK_EDGE(50)`。**

**不要动的**：
- `GOLD` 的色值。袍身提亮后，金线 vs 袍身的**亮度**比只有 **1.71:1**——这个数值是可接受的，因为金与灰靠**色相**分离（暖金 vs 中性灰），母版上交领金线同样只靠色相站着。但**金线宽度一像素都不许减**：它是袍身内部唯一的高对比元素，减宽就等于抹掉。
- `GOLD_D`（暗金 `(146,112,24)`）也不要动。它承担金线的暗部层次，改亮会让金饰在 58px 下糊成一团亮斑。
- `SKIN` / `PAPER` / 几何常量（`HIP_Y`、`HEAD_TOP` 等）。它们与 `tools/build_rig.gd` 的骨架坐标绑定。

### T2 · run / idle 的布料收幅（必做）

`shihung_rig.tscn` 里 `run`（`Animation_q7k5p`）当前的关键帧，按用户验收过的「breath」哲学处理：**腿骨交替全保留**（那是真步态），**布料脉动收到不晃**。

| 轨道 | 现值 | **改为** | 理由 |
| --- | --- | --- | --- |
| `hem_back:rotation` | `0.262 → 0.436`（摆 10°/步） | **常值 `0.30`**（不摆） | 袍摆脉动是晃动放大器，spec §12.9.1 判据 2 |
| `sash_1:rotation` | `0.559 → 0.750`（摆 11°/步） | **常值 `0.62`**（不摆） | 同上；保留常值是为了仍有"被带动"的静态倾向 |
| `sash_2:rotation` | `0.401 → 0.559` | **常值 `0.45`** | 同上 |
| `torso:position` | `0 → −1.8`（每步上下 1.8px） | **`0 → −1.4`** | 保留一点起伏给"落地有重量"，但不再读成颠 |
| `head` / `crown` rotation | 0.087→0.105 / 0.035→0.052 | **不改** | 量级仅 1°，属于呼吸滞后，不构成晃 |
| 四条腿骨 + 四条手臂骨 | — | **全部不改** | 它们是 rig 的价值所在 |

`idle`（`Animation_lqd28`）如需对齐，按 breath 的量级：**头顶上下 ≤1.5px @128 画布**（`vs` ±1.2%）。idle 现状需实现侧量一遍再定，不要凭感觉加。

### T3 · 用 AI 母版切部件替换程序化 parts（**本单不做**）

这是"把母版美术真正搬进游戏"的正解，但需要逐部件的 mask/边缘处理，属于新立项。本单只做 T1/T2，先把"能看见"和"不晃"解决。

## 5. 验收口径

**Given** 深蓝天空 `#142032`、角色按 `RIG_SCALE 0.5` 渲染（约 58px 高）
**When** 截图取袍身主色并与背景算 WCAG 对比度
**Then**

1. 袍身对比度 **≥ 3.0**（预期 3.80）；近侧袖 ≥ 4.0（预期 4.66）
2. 金冠/交领金线在 58px 下仍可辨（对天空 ≥ 6.0）
3. rig 合成图的主色不再是 `rgb(16,16,8)`

**Given** 播放 `run`
**When** 逐帧看 0.5s 一个循环
**Then**

4. `hem_back` / `sash_1` / `sash_2` **逐帧角度不变**（常值）；`torso:position` 上下行程 ≤ 1.4px
5. 四条腿骨的角度序列**与改前完全一致**（步态不受影响）
6. 循环闭合：`t = 0` 与 `t = 0.5` 的所有轨道值相同

**Given** 改完的图
**When** 与 `assets/characters/shihung/preview/char_shihung_pose_sheet.png` 对照
**Then**

7. 头身比、朝向（面朝 +x）、赤足、金冠尖数**都不变**——本单只改颜色与布料角度，不改造型
