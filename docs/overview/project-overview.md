## 当前可玩范围

第一章调查主线、私信分支、鼓将与粮道结局保留在新房间中。M05真实通往M07，后续区域拥有灯龛、档案、遗存、能力取得点及章末守印者联调战斗。全部区域可加载、探索和转图；后七章档案文本来自策划，守印者复用原型，尚未制作成完整章节叙事和专属Boss。

地图采用不同房间大小、阶形轮廓、长廊、竖井、支洞和回环，不再按平行楼层绘制。世界地图展示48区索引，区域图使用真实碰撞轮廓，支持缩放/平移和探索保存。能力依次取得后开放门槛，四凶不参与通路条件。二段跳、空冲、蹬墙、滑翔与六格生命已接入角色。

Tab目标时代卡墙时拒绝切换，提示原文，无伤且不移动。布局版本3迁移旧灯龛/遗落物坐标，保留任务、资源、流派和选择。死亡魂魄掉落可取回，再次死亡覆盖旧遗落物。

## 操作

A/D移动，空格跳，J普攻，Shift冲刺，Tab切时，E调查，Q日志，M地图，K重击，L技能，H包扎，R回灯龛，Esc设置。地图中Tab切换区域/世界，滚轮缩放，拖拽平移。语义输入支持改键与手柄默认绑定；真实硬件体验仍待验收。

## 代码入口

world_regions.json为运行时地图数据；world_data.gd构建空腔、墙体和轮廓；regions/m01.tscn至m48.tscn为独立区域实例；world_game.gd负责世界推进并复用chapter_one.gd中的调查逻辑；world_atlas.gd绘制地图。preview_world.gd提供无存档地图预览；capture_world.gd捕获实际画面。**地图生成与文档同步脚本（build_world.py、build_map_design.py、build_map_structure.py、build_m02_slice.py、build_mythic_design.py、author_chapter1_flow.py、verify_map_design.py、sync_map_docs.py、update_reconstruction_docs.py）已于2026-10-30随地图文档重建删除**，`world_regions.json` 现为唯一的运行时数据来源，手工维护直至新方案重新提供生成链路。

详见[RUN-0008](../qa/runs/RUN-0008-world-regions.md)。原世界地图说明文档已随地图文档清空（2026-10-30），地图设计待重新产出；此前M01或第一章分层说明为历史阶段。
