# 项目总览

> 状态：探索原型阶段（2026-10-25 核对）。本页区分“文件中可核查的事实”“参考资料”和“尚待团队决定”，不代表玩法、平台或交付范围已经批准。

## 已知事实

- 项目工作目录为 `GodTime/`；根目录 `project.godot` 是唯一 Godot 项目入口。立项设计案[《时间之神：类银河恶魔城游戏策划案（设定版）》](../design/时间之神：类银河恶魔城游戏策划案（设定版）.docx)位于 `docs/design/`，是设计类唯一权威来源；本页不转述其具体规则，需要引用时以原案章节为准。
- `project.godot` 当前 `config/name` 为“时间之神 - 探索原型”，`run/main_scene` 为 `res://game/main.tscn`，`config/features` 标记 `4.7` 与 `Forward Plus`。本机编辑器实测为 `4.7.2.stable.official.ed1daf0bf`，与原案“使用 Godot 4.7.2”一致。
- 显示配置：窗口拉伸 `canvas_items`、宽高比 `expand`；3D 物理引擎选项为 `Jolt Physics`；Windows 渲染设备驱动配置为 `d3d12`。这些配置项不证明项目已采用 3D 表现——当前原型全部为 2D 节点（`Node2D`、`CharacterBody2D`），与原案“纯 2D 横版”一致；`Jolt` 与 `d3d12` 目前不参与玩法。
- **已实现内容**：单个 2D 探索切片，源文件为 `game/main.tscn`、`game/player.gd`、`game/world.gd`，另有训练目标脚本 `game/training_dummy.gd`。包含左右移动、跳跃、地面冲刺、基础攻击（朝面向方向的矩形判定，含冷却与单次结算）、过去/现在时代切换（同一位置两套地形）、危险切换扣血与安全复位、坠落死亡回存档点、HUD 提示。地形以代码内常量矩形绘制，无贴图与音频资源。
- **输入层**：语义动作映射（`InputActions` 自动加载单例），支持键盘与手柄双绑定、玩家改键（Esc/Start 打开面板，写入 `user://input_bindings.cfg`）、跳跃/攻击/冲刺输入缓冲、土狼时间与松键截断上升。代码中不再出现物理键码轮询。
- **未实现内容**：重击与技能、四凶流派、敌人 AI 与 Boss、正式存档、能力成长（二段跳／空中冲刺／蹬墙／滑翔／麒麟／龙系列）、多地图与地图间连接、经济系统、导出预设与构建产物。
- **可运行回归脚本**：`tests/test_attack.gd`（攻击判定，11 项）、`tests/test_input.gd`（动作映射与改键，11 项）、`tests/test_input_feel.gd`（缓冲与土狼时间，6 项）。以 `--headless --script <路径>` 运行，`FAILURES=0` 且退出码 0 表示通过；它们**不覆盖渲染、手感与真实手柄**。
- 根目录**未检测到 `.git`**（已确认），Git 工作流尚未启用，也不存在可引用的提交号；测试与发布记录不得虚填修订标识。同样未检测到 `export_presets.cfg`，当前不能产出可发布构建。

## 项目意图与依据

[立项设计案](../design/时间之神：类银河恶魔城游戏策划案（设定版）.docx)是设计类唯一权威来源；其“一、项目概况与体验目标”写明品类为纯 2D 横版类银河恶魔城、目标平台为 Steam、视觉方向为 2D 水墨。玩法循环、时间能力细则、四凶流派数值与美术规格，须经团队从案内核对后写入对应分类文档。立项案本身不代表其中每项方案均已批准或实现，概念描述不应代替可验收需求。

已实现的时间切换原型与原案“二、时间切换与安全复位”的对照与偏差，登记在[功能规格：时间切换](../design/feature-time-switch.md)。

## 下一步建议

1. 按[功能规格：时间切换](../design/feature-time-switch.md)的待确认项，由设计负责人逐条确认与原案的偏差（尤其安全复位判据与攻击数值基线），避免原型行为被误当作已批准规则。
2. 基础攻击已补齐并通过自动断言；下一步需在带窗口的会话中人工确认打击感与命中反馈，并把结果补记为 `RUN-0002`。是否先建立输入映射以支撑手柄与重映射，待团队决定。
3. 工程协作按[开发规范](../development/development-guidelines.md)执行；测试证据与发布要求分别维护在 `qa/`、`release/`。已有的原型运行记录见 [RUN-0001](../qa/runs/RUN-0001-prototype-smoke.md)。
4. 在初始化 Git 仓库前，`docs/qa/` 与 `docs/release/` 中的“构建标识”只能使用文件 SHA-256，或明确标注为无版本控制的临时标识。
