# 美术与视觉文档

本目录存放**美术方向、视觉规范与资产登记文档**，不是图片、模型或其他可被游戏直接加载的素材目录。项目当前仅有 Godot 默认 `res://icon.svg`，不将其视为已确立的游戏视觉风格。玩法设定参考立项案[《时间之神：类银河恶魔城游戏策划案（设定版）.docx》](../design/时间之神：类银河恶魔城游戏策划案（设定版）.docx)；其中未获确认的视觉描述不得写成既定规范。

## 素材与文档分离

- `docs/art/`：决策、参考链接、生产规格和资产登记；不要将仅供参考的第三方作品当作可交付游戏素材。
- 未来实际素材应存放在项目资源目录（例如 `res://assets/`），**目录位置需与工程负责人确认后启用**；源工程文件、导出文件的放置方式也需在管线确定后约定。
- 已进入场景或脚本的素材，在资产登记中记录准确的 `res://` 路径及引用场景；替换素材前核对引用，不依赖临时文件名。

## 建议命名与登记规则

使用小写英文、数字和下划线，按 `类别_对象_用途_变体` 描述语义，例如 `ui_time_meter_fill_01.png`。这只是**待确认的建议约定**，不预设二维/三维、画幅、像素风或最终文件格式；不要直接给现有 `icon.svg` 改名。具有序列帧或状态的资产应在登记里解释编号与状态，并保持同一资产族的命名一致。

新增资产至少记录：

| 字段 | 填写要求 |
| --- | --- |
| 资产 ID / 名称 / 类别 | 唯一可检索标识；注明角色、场景、UI、特效等实际用途 |
| 状态 / 负责人 / 日期 | 需求、草稿、待审、批准、入库等状态及更新时间 |
| 需求依据 / 使用场景 | 指向已确认的设计文档及具体使用位置；未知则标“待确认” |
| 视觉规格 | 风格规范版本、视角、尺寸/比例、透明度、色彩空间、动画帧数或时长（按类型选填） |
| 技术规格 | 源文件与导出格式、导出尺寸、资源路径、导入设置、性能预算；由目标平台与渲染管线决定 |
| 来源 / 作者 / 授权 | 自制、委托、商用素材、AI 辅助等；保存来源链接、许可证名称或合同凭证、许可范围及署名要求 |
| AI 辅助记录 | 如使用，记录模型/工具、提示词或制作流程、参考素材来源及商用与再分发许可核验结果 |
| 验收 / 引用 | 审核人、批准版本、实际 `res://` 路径、关联场景及可访问性检查结果 |

**授权底线：**未能核实来源和项目所需的使用、修改、商用及分发权限的素材，不进入正式资源库；“网上找到”或生成得到均不等于已获授权。参考图与可发布资产分开登记。

## 方向决策与验收

在制作前请用户确认：视觉参考与禁用参考、目标平台和屏幕规格、二维/三维表现形式、可访问性目标、性能预算与素材授权边界。确定后再编写美术圣经和逐项资产规格，不依据项目名称自行推定配色或画风。视觉信息不能只靠颜色区分；UI 状态应同时考虑形状、文字或图标，最终对比度、字体缩放与降低闪烁/运动的要求以确认后的可访问性规范为准。
